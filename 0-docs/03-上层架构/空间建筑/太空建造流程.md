# 太空建造流程

> 目标：定义一个统一的、由玩家规划和运输舰执行的太空建造流程，适用于所有太空设施（包括采集设施、船坞、交通设施等）。

## 1. 核心理念

- **玩家决策，AI执行**：玩家负责“在哪里建”和“建什么”的战略决策，而具体的资源运输和建造过程则由帝国的自动化物流系统（运输舰）执行。
- **资源驱动**：建造的进度完全由所需资源的到位情况决定。

---

## 2. 建造流程三阶段

### 2.1 规划阶段 (Planning Phase)

1.  **玩家操作**：玩家通过建造UI选择一个想要建造的太空设施（如“太空航道”、“气态采集平台”等）。
2.  **指定位置**：玩家在合法的建造位置（如恒星系引力范围边缘）点击，放置一个“**建造投影**”（Construction Site）。
3.  **系统响应**：
    *   一个半透明的、代表该设施最终样貌的投影出现在指定位置。
    *   系统会立即从**国家财政账户**中扣除该设施的**基础成本**（信用点/货币）。
    *   系统会根据该设施所需的**物资资源**（如合金、晶体等），生成一个或多个**运输任务**。

### 2.2 物流阶段 (Logistics Phase)

1.  **任务分配**：新生成的运输任务会进入帝国的物流系统，并根据其优先级（详见《运输与物流.md》）等待分配。
2.  **运输舰执行**：一艘或多艘空闲的**运输舰**会接受任务，从最近的、拥有足够资源的节点（如行星、仓库空间站）装载所需物资，并将其运往“建造投影”所在的位置。

### 2.3 建造阶段 (Construction Phase)

1.  **资源交付**：当运输舰到达“建造投影”并交付资源后，建造进度开始推进。
2.  **进度推进**：建造的**当前进度**与**已交付资源占总需求资源的百分比**成正比。
    `建造进度 (%) = (已交付资源价值 / 总需求资源价值) * 100`
3.  **建造完成**：当所有必需的资源都已交付（即进度达到100%）后，“建造投影”转变为一个功能齐全的、已建成的太空设施。

---

## 3. 约束与口径

- **并行建造**：玩家可以同时规划多个建造项目，但实际的建造速度将受限于帝国的资源产量和运输舰的运力。
- **取消建造**：玩家可以随时取消一个正在进行中的建造项目。取消后，已投入的基础成本和已运输到现场的物资将按一定比例（例如80%）返还。
- **引用**：所有太空设施文档（如《太空设施.md》、《交通设施.md》）中的“建造规则”，都应引用本统一流程，而无需重复描述。
