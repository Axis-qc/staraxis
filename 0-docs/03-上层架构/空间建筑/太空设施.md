# 太空设施

> 目标：定义玩家可以在恒星系内建造的各类功能性太空设施，包括采集设施和太空船坞，并明确其功能、等级和升级路径。

## 1. 建造规则（通用）

所有太空设施的建造都遵循统一的太空建造流程：

1.  **玩家规划**：玩家通过建造UI在合法的建造位置（如行星轨道、恒星轨道、小行星带）指定要建造的设施。
2.  **运输舰建造**：系统自动创建运输任务，派遣运输舰运送所需资源到建造点，随资源的到达推进建造进度。

> **详情参见**：`开发文档/空间建筑/太空建造流程.md`

## 2. 采集设施 (Harvesting Facilities)

采集设施用于从行星或恒星本身获取资源，是地表产出的重要补充。

### 2.1 气态轨道采集平台 (Gas-Giant Orbital Platform)

- **建造位置**：气态巨行星的轨道上。
- **功能**：采集该气态巨行星特有的稀有气体资源（如氦-3）。
- **升级路径**：
  - **等级1 (平台)**：基础的采集平台，提供少量产出。
  - **等级2 (采集环)**：可升级为环绕整个行星的“采集环”，显著提升采集效率和产出量。

### 2.2 恒星能源站 (Stellar Energy Station)

- **建造位置**：恒星的轨道上（通常在较近的轨道）。
- **功能**：利用恒星的能量，大量产出能源（Energy）。
- **升级路径**：可升级以提升能源产出效率或增加额外的功能（如科研产出）。

### 2.3 小行星采矿平台 (Asteroid Mining Platform)

- **建造位置**：小行星带或富含矿物的小行星上。
- **功能**：开采矿物或其他稀有晶体资源。

## 3. 太空船坞 (Space Shipyard)

太空船坞是建造、维护和管理舰队的核心设施。

### 3.1 船坞类型

- **军用港 (Military Shipyard)**：
  - **功能**：
    1.  **建造战斗舰船**：负责建造、维护和升级所有**战斗舰船**。
    2.  **提供补给舰上限**：决定了帝国总共能拥有的**补给舰**的最大数量。
    3.  **自动建造补给舰**：当现有的补给舰数量低于上限时，军用港会自动、缓慢地建造新的补给舰，直到达到上限，此过程消耗资源。
  - **核心属性**：其等级决定了可建造的战斗舰船规模上限和并行建造容量（详见《舰船与模块.md》）。

- **民用港 (Civilian Dock)**：
  - **功能**：
    1.  **提供运输舰数量上限**：决定了帝国总共能拥有的**运输舰**的最大数量。
    2.  **自动建造运输舰**：当现有的运输舰数量低于上限时，民用港会自动、缓慢地建造新的运输舰，直到达到上限，此过程消耗资源。

### 3.2 升级路径：环形结构

- **概念**：太空船坞可以围绕一个行星或恒星进行多次升级，每次升级都会增加其环形结构的规模。
- **升级收益**：
  - 提升港口等级。
  - **军用港**：增加“战斗舰船建造规模上限”和“建造容量”，并提升“补给舰数量上限”和自动建造速度。
  - **民用港**：提升“运输舰数量上限”和自动建造速度。
  - 解锁新的船坞模块，提供额外的舰队加成（如增加初始经验、减少维护费等）。

## 4. 其他太空设施

- **防御平台 (Defense Platform)**：自动攻击进入射程的敌方单位。
- **探测器 (Sensor Array)**：提升所在恒星系的索敌范围和情报等级。
- **空间站 (Space Station)**：多功能平台，可以安装各种模块以提供贸易、科研、居住等多种功能。
