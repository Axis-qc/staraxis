## 1. 项目一句话

**StarAxis** 是一个以“单机权威模拟”为中心的 2D 俯视角太空 4X 大战略游戏项目：

- **权威世界状态**：单机进程内维护权威世界状态（未来为 `WorldState`）。
- **客户端职责**：负责窗口/输入/渲染/UI 表现，不决定模拟结果。
- **game**：游戏模拟层，负责游戏实际推进，接收ui层指令影响游戏推进。

## 3. 你需要牢记的 6 条硬规则

1. **模拟层权威**：所有改变游戏结果的逻辑只在模拟层执行。
2. **确定性优先**：相同输入与初始状态必须得到相同结果（为存档对账服务）。
3. **模拟时间驱动**：推进与结算绑定 `simulationTick`（本地模拟 Tick）` / `gameDatetimeDay`，不能由 FPS 驱动。
4. **多核并行是强制项**：可并行计算要拆 Job；但权威写入必须在“落账点”串行化。
5. **双快照口径**：
   - `上一日结算状态（DailySettlementState）`：UI 层展示经济/生产/人口等具有固定结算周期（按“日”）的数据（避免读取计算中间态）。
   - `实时世界状态（RealTimeWorldState）`：战斗、移动、即时事件等实时系统；以及需要即时数据的 UI 展示。
6. **命名/术语统一**：所有字段写法必须一致，正文出现字段必须用 `fieldName`（解释）格式。
7. **代码必须带注释**：所有代码都必须带注释，禁止不写注释。

## 4. 游戏运行逻辑（当前工程口径）

> 本节描述“应用启动链路”和“模块调用关系”，便于快速定位入口与职责边界。

### 4.1 启动链路（lwjgl3 → client → ui → game）

- `lwjgl3`（桌面端启动器）负责创建桌面窗口与启动 LibGDX 应用。
- `client`（客户端应用层）负责组织游戏运行：
  - 启动/管理 UI（调用 `ui` 模块）
  - 启动/驱动游戏模拟（调用 `game` 模块；当前仅预留，未接入）
- `ui`（UI 层）只负责 UI 展示与交互（Scene2D），不包含模拟规则。
- `game`（游戏逻辑层）负责权威模拟（未来接入），不依赖渲染库或 UI。

### 4.2 当前可运行入口

- **桌面启动入口**：`lwjgl3/src/main/java/staraxis/lwjgl3/Lwjgl3Launcher.java`
- **客户端应用入口（LibGDX ApplicationListener）**：`client/src/main/java/staraxis/ClientGame.java`

## 5. UI 资源依赖（离线加载）

> UI 必须完全离线加载，不得依赖外网资源。运行时 workingDir 以 `assets/` 为准（`lwjgl3` 已配置）。

### 5.1 Scene2D 皮肤资源（uiskin）

- `assets/ui/uiskin.json`（Scene2D Skin 定义）
- `assets/ui/uiskin.atlas` / `assets/ui/uiskin.png`（Skin 贴图资源）

### 5.2 UI 字体资源（TTF）

- 默认中文字体：`assets/fonts/chinese/AlibabaPuHuiTi-3-65-Medium.ttf`
- UI 会先使用 LibGDX 默认 `BitmapFont` 作为兜底字体，再尝试用 TTF 生成字体并覆盖；若 TTF 生成失败则保持兜底字体，避免启动崩溃。

## 6. 核心数据流（读懂这段就能开始干）

> 注意：本节描述的是“最终目标口径”。当前工程阶段优先打通 UI 主菜单，模拟层尚未接入。

### 6.1 从 UI 层到模拟层

- UI 层把玩家操作封装为 **Command（指令）** 发给模拟层。
- 模拟层校验/排队后，在主循环 tick 内执行该指令，改变权威 `WorldState`。

### 6.2 从模拟层回到 UI 层

- 模拟层把权威变化输出为：

- `实时世界状态（RealTimeWorldState）`
- 用于战斗、移动、即时事件等实时系统；以及需要即时数据的 UI 展示。

- `上一日结算状态（DailySettlementState）`
- 用于 UI 层展示经济/生产/人口等具有固定结算周期（按“日”）的数据。

### 6.3 UI 为什么“看上去慢一拍”

项目采用“日结算 0 点落账”的账本口径：

- UI 面板默认展示的是 **上一日结算状态（DailySettlementState）**。
- 今日正在计算中的账本数据不直接暴露给 UI（避免读到半成品、避免跨线程争用）。
