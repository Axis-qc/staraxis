# 游戏目录结构设计（单机模式，推荐方案）

> 目标：在单机模式下，为 StarAxis 提供一套**长期可演进**、**便于扩展**、**便于打包**的项目目录结构。
>
> 本文档是“目录结构的权威口径”，用于约束：
> - 代码放哪、资源放哪、存档放哪、日志/配置放哪
> - JCEF Web UI（HTML）与 OpenGL 原生渲染的协作边界
> - 未来经济/战斗/世界生成等功能模块如何落盘与组织
>
> 参考：
> - [客户端设计方案](../01-底层架构/11客户端设计方案.md)
> - [模拟时间](../01-底层架构/模拟时间.md)
> - [存档与读档](../01-底层架构/存档与读档.md)

---

## 1. 设计约束（来自底层架构文档）

- **单机权威**：`WorldState` 常驻内存，`simulationTick` 驱动实时系统；跨日后生成 `DailySettlementState` 供 UI 展示。
- **ID 索引模型**：所有实体用 ID 索引；跨 tick 不持有权威对象引用。
- **渲染分层**：下层 OpenGL 原生画面；上层 JCEF WebView（HTML UI）叠加渲染。
- **存档**：写入实体文件（建议扩展名 `.sav`），必须包含 `gameVersion`，采用原子写入；支持有限向前兼容。

## 3. 现状与迁移建议（基于当前仓库）

当前仓库已存在：
- `0-docs/`：已作为文档根目录
- `assets/`：资源根目录（已存在 `ui/gameui` 与 `ui/hud`）
- `lwjgl3/`：桌面端启动与打包模块
- `lwjgl3/natives/jcef-windows/`：JCEF Windows 原生包（已落地）

建议迁移路径（不强制一次到位）：
- **阶段 1（当前）**：保留 `lwjgl3` 作为唯一可运行模块；先把单机逻辑/存档/系统模块按包结构在 `lwjgl3` 或其依赖模块中落地。
- **阶段 2（推荐）**：逐步恢复/引入 `engine/`、`game/`、`ui/` 三个模块（或 Gradle 子模块），将平台相关与业务逻辑解耦。

## 4. 资源目录规范（assets）

### 4.1 UI 资源（JCEF Web UI）

- UI 资源位于：`assets/ui/`
- 必须按功能分类组织：
  - `assets/ui/gameui/`：主菜单、设置、存档管理、国家选择、世界生成、舰船设计器等页面
  - `assets/ui/hud/`：HUD 相关资源

### 4.2 资源加载口径

- 运行时工作目录指向 `assets/`（当前 `lwjgl3` 已采用该口径）。
- UI 页面通过 `file://` 或等价本地方式加载，禁止依赖外网资源。

---

## 5. 存档/配置/蓝图目录规范（gamedata）

### 5.1 存档（Save）

- 默认目录：`gamedata/saves/`
- 推荐扩展名：`.sav`
- 文件名建议包含：存档名 + 时间戳（便于管理）

### 5.2 用户设置（Config）

- 默认目录：`gamedata/config/`
- 用于保存：分辨率、最大帧数、是否全屏、画质选项等

### 5.3 舰船蓝图（Blueprint）

- 默认目录：`gamedata/blueprints/`
- 蓝图与存档解耦，可独立导入/导出

### 5.4 日志（Logs）

- 默认目录：`gamedata/logs/`

### 5.5 Mod 加载与覆盖规则（Mods）

- Mod 目录：`gamedata/mods/`
- Mod 启用与排序：由游戏内 UI 手动管理（玩家可调整顺序）。
- 加载顺序：按 UI 中的排序依次读取；越靠后加载的 Mod 优先级越高。
- 覆盖规则：同一资源/数据 key 冲突时，采用“后读覆盖前读”（last-wins）。
- 建议结构（最小约定）：
  - `gamedata/mods/<modId>/`：单个 Mod 根目录
  - `gamedata/mods/<modId>/assets/`：该 Mod 提供的运行时资源（与 `assets/` 保持相对路径一致）
  - `gamedata/mods/<modId>/data/`：该 Mod 提供的数据文件（如数值表/定义），与 `assets/data/` 约定保持一致

## 6. 未来功能模块的落盘建议（按系统划分）

> 这里不规定类名/实现细节，只规定“模块边界与目录归属”。

- **世界生成**：`game/worldgen/`（或 `0-docs/02-中层架构/世界生成系统` 对应代码模块）
- **经济系统**：`game/systems/economy/`
- **战斗系统**：`game/systems/combat/`
- **AI 系统**：`game/systems/ai/`
- **事件系统**：`game/systems/events/`
- **存档系统**：`game/save/`
- **模拟时间**：`game/time/`（实现 `simulationTick/timeScale/dtGameHours` 口径）

## 7. 命名与提交约定

- **目录命名**：优先使用英文 `kebab-case`（例：`world-gen/`）。
- **代码标识符**：英文；文档与注释使用简体中文。
- **用户数据目录（gamedata）**：默认不提交到仓库（应加入 `.gitignore`）。
