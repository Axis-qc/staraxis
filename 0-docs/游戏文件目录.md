# StarAxis 项目目录结构

> 目标：让新开发者 1 分钟内定位“核心模块在哪、资源在哪、启动入口在哪”。
>
> 说明：仓库处于单机模式重构阶段。本文件只展示**当前主要目录**（与仓库真实目录保持一致）。

```text
staraxis/

├── 0-docs/                           # 文档目录（与游戏代码无关；此处不展开）
├── assets/                           # 游戏资源（与游戏代码无关；此处不展开）
├── gamedata/                         # 存档与用户数据（与游戏代码无关；此处不展开）
├── specs/                            # 规格产物（与游戏代码无关；此处不展开）
├── gradle/                           # Gradle wrapper（与游戏代码无关；此处不展开）
│
├── client/                           # 客户端应用层（组织 UI 与 game；不承载权威规则）
│   └── src/main/java/
│       └── staraxis/
│           ├── ClientGame.java                     # 客户端应用入口（ApplicationListener 实现）
│           ├── UiPreviewApp.java                   # UI 预览用的 App 入口（用于快速查看 UI）
│           └── logging/
│               └── GdxToSlf4jLogger.java           # 将 GDX 日志桥接到 SLF4J
│
├── ui/                               # UI 层模块（Scene2D；只读展示，不写权威世界）
│   ├── src/main/java/
│   │   └── staraxis/ui/
│   │       ├── FontProvider.java                   # 字体提供与兜底策略
│   │       ├── Gui.java                            # UI 总入口/管理器（Screen 切换等）
│   │       ├── UiSkinLoader.java                   # UI Skin/资源加载器
│   │       ├── console/
│   │       │   ├── ConsoleCommand.java             # 控制台命令定义
│   │       │   ├── ConsoleOutput.java              # 控制台输出模型
│   │       │   ├── DevConsole.java                 # 开发者控制台逻辑
│   │       │   └── DevConsoleView.java             # 开发者控制台视图
│   │       ├── i18n/
│   │       │   └── I18nService.java                # UI 国际化服务（加载/查找文本）
│   │       ├── json/
│   │       │   ├── ComponentNode.java              # 声明式 UI 的节点数据结构
│   │       │   ├── UiFactory.java                  # UI 控件工厂（从节点/数据构建具体控件）
│   │       │   └── UiParser.java                   # 解析 UI JSON/结构为节点树
│   │       ├── screens/
│   │       │   ├── MainMenuScreen.java             # 主菜单 Screen
│   │       │   └── SettingsScreen.java             # 设置 Screen
│   │       ├── settings/
│   │       │   ├── GameSettings.java               # 游戏设置数据模型
│   │       │   └── SettingsRepository.java         # 设置读写/持久化仓库
│   │       ├── utils/
│   │       │   └── DragAndClampListener.java       # 拖拽并限制在窗口范围内的监听器
│   │       └── widgets/
│   │           └── DevelopingDialog.java           # 开发中提示弹窗
│   └── src/main/resources/
│       └── ui/
│           └── component.schema.json               # 声明式 UI 组件 Schema（校验/约束）
│
├── game/                             # 游戏逻辑层模块（权威模拟；推进 WorldState）
│   └── src/main/java/
│       └── staraxis/game/
│           ├── GameRuntime.java                    # 游戏运行时接口/抽象（模拟驱动入口）
│           └── SimpleGameRuntime.java              # 简单实现（当前骨架/占位）
│
├── lwjgl3/                           # 桌面端启动器（创建窗口/启动 LibGDX；平台层）
│   └── src/main/
│       ├── java/staraxis/lwjgl3/
│       │   ├── Lwjgl3Launcher.java                # 桌面端启动入口（创建配置并启动 client）
│       │   ├── UiPreviewLauncher.java              # UI 预览启动入口（桌面端）
│       │   └── StartupHelper.java                 # 启动辅助（平台/路径/兼容性处理）
│       └── resources/
│           ├── logback.xml                         # 日志配置（Logback）
│           ├── libgdx16.png                        # 应用图标资源
│           ├── libgdx32.png
│           ├── libgdx64.png
│           └── libgdx128.png
│
├── build.gradle                      # 根构建脚本（与游戏代码无关；此处不展开）
├── settings.gradle                   # 多模块声明（与游戏代码无关；此处不展开）
└── gradle.properties                 # Gradle 参数（与游戏代码无关；此处不展开）
```

## 关键入口文件

- **桌面端启动入口**：`lwjgl3/src/main/java/staraxis/lwjgl3/Lwjgl3Launcher.java`
- **客户端应用入口（LibGDX ApplicationListener）**：`client/src/main/java/staraxis/ClientGame.java`
- **UI 预览启动入口**：`lwjgl3/src/main/java/staraxis/lwjgl3/UiPreviewLauncher.java`

## 模块依赖关系（当前仓库实际）

- `lwjgl3`：桌面端启动与打包模块（平台层）
- `client`：客户端应用层（组织 UI 与 game，驱动主循环）
- `ui`：UI 层模块（被 `client` 依赖）
- `game`：游戏逻辑层模块（被 `client` 依赖；当前仍在骨架阶段）

## 备注

- `assets/ui/` 下的 UI 皮肤/贴图资源以实际内容为准（当前仓库未发现 `assets/ui/uiskin.json`，如后续引入请同步更新本文件）。
- 若你希望目录树进一步细化到 `src/main/java/...` 的具体包路径与关键类（例如 UI 主菜单入口类），我也可以继续补齐。
