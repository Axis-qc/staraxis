# StarAxis 项目目录结构

> 目标：设计实际可落地项目结构
> 
> 说明：本文件已于 2026-01-14 更新，以反映项目迁移到 `core/client/server/shared` 多模块结构并缩短包名后的最终状态。

```text
# StarAxis 游戏开发目录结构

staraxis/
├── assets/                          # 游戏资源（所有模块共享）
│   ├── effect/                     # 特效资源
│   │   ├── PNG (Black background)/ # 特效 PNG（黑底）
│   │   └── PNG (Transparent)/      # 特效 PNG（透明底）
│   ├── fonts/                      # 字体文件
│   │   ├── AlibabaPuHuiTi-3-65-Medium.ttf  # 阿里巴巴普惠体
│   │   └── NotoSansSC-Regular.ttf  # 思源黑体（简体中文）
│   ├── ui/                         # UI 资源（客户端/工具共享，非代码）
│   │   ├── gameui/                 # 游戏 UI 资源
│   │   └── hud/                    # HUD 资源
│   ├── world/                      # 世界/背景资源
│   ├── data/                       # 游戏资源
│   │   ├── planet/                 # 星球纹理资源等
│   │   └── shipmodule              # 舰船模块资源（纹理，配置文件等）
│   └── i18n/                       # 本地化文本
│
├── docx/                            # 项目文档（权威设计/规范/方案）
│   ├── 00-通用规范与治理/
│   ├── 01-底层架构-放弃服务端/
│   ├── 02-中层架构/
│   ├── 03-上层架构/
│   └── 04-UI与表现层/
│
├── specs/                           # 需求规格（Speckit 产物）
│   ├── 001-game-design-bible/
│   ├── 002-loop-comms-skeleton/
│   ├── 003-webview-ui/
│   └── main/
│
├── lwjgl3/                           # 桌面端启动壳（仅平台相关）
│   ├── build.gradle                 # 桌面端打包/运行配置（workingDir 指向 assets）
│   ├── icons/                       # 打包图标
│   ├── natives/                     # 本地原生依赖（随项目管理/随打包分发）
│   │   └── jcef-windows/            # JCEF Windows 原生包（Chromium 运行依赖）
│   ├── src/
│   │   └── main/
│   │       ├── java/
│   │       │   └── staraxis/lwjgl3/ # 桌面端启动代码包
│   │       │       ├── Lwjgl3Launcher.java    # 桌面启动器
│   │       │       ├── UiPreviewLauncher.java # UI 预览启动器
│   │       │       └── StartupHelper.java     # 启动辅助
│   │       └── resources/           # 桌面端资源（通常从 assets 聚合）
│   └── nativeimage.gradle           # Graal NativeImage（可选）
│
├── gradle/                          # Gradle wrapper
├── .specify/                        # 开发规范（IDE/流程/模板等）
│
├── build.gradle                     # 根项目构建配置
├── gradle.properties                # Gradle 属性（版本号等）
└── settings.gradle                  # Gradle 模块配置（当前 include 列表可能滞后，需与实际目录一致）
```

## 关键入口文件

- **桌面端启动入口**：`lwjgl3/src/main/java/staraxis/lwjgl3/Lwjgl3Launcher.java`
- **UI 预览启动入口**：`lwjgl3/src/main/java/staraxis/lwjgl3/UiPreviewLauncher.java`
