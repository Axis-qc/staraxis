# StarAxis 项目目录结构

> 目标：让新开发者 1 分钟内定位“核心模块在哪、资源在哪、启动入口在哪”。
>
> 说明：仓库处于单机模式重构阶段。本文件只展示**当前主要目录**（与仓库真实目录保持一致）。

```text
staraxis/

├── assets/                          # 游戏资源（运行时读取；工作目录通常指向此处）
│   ├── assets.txt
│   ├── effect/
│   ├── fonts/
│   │   ├── chinese/
│   │   │   └── AlibabaPuHuiTi-3-65-Medium.ttf
│   │   └── english/
│   ├── ui/
│   │   ├── hud/
│   │   ├── gameui/
│   │   └── uiskin.json
│   └── world/
│
├── lwjgl3/                           # 桌面端启动器（平台相关；当前可运行入口）
│   ├── build.gradle
│   ├── natives/
│   │   └── jcef-windows/             # 旧遗留（当前主菜单已切换为 Scene2D）
│   └── src/main/java/staraxis/lwjgl3/
│       ├── Lwjgl3Launcher.java
│       ├── UiPreviewLauncher.java
│       └── StartupHelper.java
│
├── ui/                               # 游戏 UI 层（Scene2D；包含 Gui 管理器/主菜单/弹窗等）
│   └── src/main/java/
│
├── game/                             # 游戏逻辑层（当前为空/仅目录骨架）
│   └── src/main/java/
│
├── gamedata/                         # 存档与用户数据
│   ├── saves/
│   ├── logs/
│   ├── mods/
│   └── screenshots/
│
├── 0-docs/                           # 权威文档
├── specs/                            # 规格产物（Speckit）
├── gradle/                           # Gradle wrapper
├── build.gradle
├── gradle.properties
└── settings.gradle
```

## 关键入口文件

- **桌面端启动入口**：`lwjgl3/src/main/java/staraxis/lwjgl3/Lwjgl3Launcher.java`
- **UI 预览启动入口**：`lwjgl3/src/main/java/staraxis/lwjgl3/UiPreviewLauncher.java`

## 模块依赖关系（当前仓库实际）

- `lwjgl3`：桌面端启动与打包模块
- `ui`：UI 层模块（被 `lwjgl3` 依赖）
- `game`：逻辑层模块（当前仅目录骨架，暂未接入）

## 备注

- `game` 模块目前不包含模拟层/世界状态等实现，本阶段只完成主菜单 UI。
- `assets/ui/uiskin.json` 已作为 Scene2D UI 的基础皮肤资源入口。
