### 🔧 技术细节

#### 路径解析逻辑：
```python
def _get_shard_path(self, shard_filename: str) -> str:
    # 首先尝试直接路径
    shard_path = os.path.join(self.conversations_dir, shard_filename)
    if os.path.exists(shard_path):
        return shard_path

    # 如果是分层路径但文件不存在，尝试根目录查找（旧格式兼容）
    if '/' in shard_filename:
        basename = os.path.basename(shard_filename)
        root_path = os.path.join(self.conversations_dir, basename)
        if os.path.exists(root_path):
            return root_path

    return shard_path  # 返回原始路径（后续会跳过）
```

#### 存储策略：
