这是 StarAxis 游戏前端渲染层迁移工作的一部分，将现有的行星渲染功能从旧架构迁移到新的分层架构。`LayerPlanetRenderer` 是 `CelestialLayer` 的一部分，负责渲染所有行星实体。

## 工作内容

### 1. 添加后备纹理创建方法
在 `LayerPlanetRenderer` 类中实现了 `createCircleTexture()` 方法，用于创建后备圆形纹理喵。
- 使用 HTML Canvas 创建 64x64 像素的圆形纹理
- 采用径向渐变效果，中心白色，边缘半透明
- 返回 THREE.CanvasTexture 供精灵使用

### 2. 实现init方法
替换了原有的 `init()` 方法，实现完整的初始化逻辑喵：
- 创建后备圆形纹理并存储到 `fallbackCircleTexture` 属性
- 预创建精灵对象池（20个 THREE.Sprite 实例）
- 每个精灵使用基础白色材质，初始设置为不可见
- 将所有精灵添加到父组并存入对象池
- 输出初始化日志

### 3. 实现精灵对象池管理方法
添加了两个私有方法管理精灵对象池喵：
- `acquirePlanetSprite()`：从对象池获取可用精灵，如果池为空则创建新精灵
- `releasePlanetSprite(sprite: THREE.Sprite)`：释放精灵回池，重置材质映射并设为不可见
