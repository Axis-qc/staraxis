### 详细实现

#### 2.1 后备纹理创建方法
```typescript
private createCircleTexture(): THREE.CanvasTexture {
  const canvas = document.createElement('canvas')
  canvas.width = 64
  canvas.height = 64
  const ctx = canvas.getContext('2d')!

  // 绘制径向渐变圆形
  const gradient = ctx.createRadialGradient(32, 32, 0, 32, 32, 30)
  gradient.addColorStop(0, 'rgba(255, 255, 255, 1)')
  gradient.addColorStop(0.8, 'rgba(255, 255, 255, 1)')
  gradient.addColorStop(1, 'rgba(255, 255, 255, 0.8)')

  ctx.arc(32, 32, 30, 0, Math.PI * 2)
  ctx.fillStyle = gradient
  ctx.fill()

  return new THREE.CanvasTexture(canvas)
}
```

**技术特点：**
- 64×64 像素 Canvas 纹理
- 径向渐变效果：中心白色不透明，边缘半透明
- 用于行星缩小到像素级别时的后备显示

#### 2.2 完整 init 方法
```typescript
init(ctx: WorldRenderContext): void {
  this.context = ctx
  this.fallbackCircleTexture = this.createCircleTexture()

  // 预创建精灵对象池（20个）
  for (let i = 0; i < 20; i++) {
    const material = new THREE.SpriteMaterial({
      color: 0xffffff,
      sizeAttenuation: true,
    })
    const sprite = new THREE.Sprite(material)
    sprite.visible = false
    this.parentGroup.add(sprite)
    this.planetSpritePool.push(sprite)
  }

  console.log('LayerPlanetRenderer initialized')
}
```

**初始化流程：**
1. 存储渲染上下文
2. 创建后备圆形纹理
3. 预创建 20 个精灵对象池
4. 输出初始化日志

#### 2.3 精灵对象池管理

**获取精灵：**
```typescript
private acquirePlanetSprite(): THREE.Sprite {
  const sprite = this.planetSpritePool.pop()
  if (sprite) {
    sprite.visible = true
    return sprite
  }
  // 池为空时创建新精灵
  const newSprite = new THREE.Sprite(new THREE.SpriteMaterial({
    color: 0xffffff,
    sizeAttenuation: true,
  }))
  this.parentGroup.add(newSprite)
  return newSprite
}
```

**释放精灵：**
```typescript
private releasePlanetSprite(sprite: THREE.Sprite): void {
  const material = sprite.material as THREE.SpriteMaterial
  material.map = null  // 清除纹理引用
  sprite.visible = false
  this.planetSpritePool.push(sprite)
}
```

**对象池设计：**
- **空闲池：** `planetSpritePool: THREE.Sprite[]` 数组
- **激活映射：** `activePlanetSpritesByEntityId: Map<number, THREE.Sprite>`
- **池大小：** 预创建 20 个，动态扩展
- **内存管理：** 及时释放纹理引用，避免内存泄漏
