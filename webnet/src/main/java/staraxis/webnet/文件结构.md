# webnet 模块目录结构

> `webnet` 模块负责对外提供 HTTP/WebSocket 等网络服务，承接上层请求并与 `game` 模块交互，向客户端发布只读快照与业务数据。

---

webnet/src/main/java/staraxis/webnet
|-- AccountFiles.java           # **账号文件路径工具**：统一管理本地账号数据目录/文件路径（gamedata/accounts），并提供列举账号文件等操作。
|-- AuthStore.java              # **认证与会话存储**：本地账号注册/登录、PBKDF2 密码校验、token->Session 内存映射，并支持写入玩家 gameId。
|-- GameLog.java                # **服务端日志**：将运行日志写入 gamedata/logs/game.log（初始化截断、追加写、关闭）。
|-- I18nApi.java                # **i18n API**：扫描并合并本体与已启用 Mods 的语言包（.properties），提供可用语言列表与合并后的字符串表。
|-- ModManager.java             # **Mod 顺序/启用口径**：读取 mod-order.json 并扫描 mods 目录，输出"按顺序且已启用"的 modId 列表。
|-- ModMetadata.java            # **Mod 元信息模型**：对应 gamedata/mods/<modId>/mod.json 的数据结构，用于 /api/mods 返回。
|-- ModOrder.java               # **Mod 顺序配置模型**：对应 gamedata/mods/mod-order.json（schemaVersion/order/disabled）。
|-- ModOrderRepository.java     # **Mod 顺序配置仓库**：读取并解析 gamedata/mods/mod-order.json，失败时返回默认配置。
|-- WebNetLauncher.java         # **启动入口（main）**：解析 host/port/autoExitSeconds 等参数，启动 WebNetServer，并尝试打开浏览器到 /webui/。
|-- WebNetServer.java           # **HTTP + WebSocket 服务端**：基于 Undertow 提供 /api/** 与 /ws，并驱动 game tick 广播快照。
|-- WebNetServerConfig.java     # **服务端配置载体**：封装 host/port/autoExitSeconds 等运行配置（含兼容字段）。
|-- 文件结构.md                  # 本文件：目录结构索引
|

|   `-- WebCommandRegistry.java # **命令注册表**：管理命令处理器注册、查询与统一处理入口。

|-- ModOrder.java               # **Mod 顺序配置模型**：对应 gamedata/mods/mod-order.json（schemaVersion/order/disabled）。
|-- ModOrderRepository.java     # **Mod 顺序配置仓库**：读取并解析 gamedata/mods/mod-order.json，失败时返回默认配置。

|-- 文件结构.md                  # 本文件：目录结构索引
|
|-- api/                        # **HTTP API 逻辑**：按业务域拆分的 API 辅助/handler 逻辑，由 `WebNetServer` 负责路由挂载。
|   |-- nation/                 # **国家相关 API**：预设国家读取、玩家自定义国家的增删改查。
|   |   |-- NationPresetsApi.java # **预设国家 API**：读取 gamedata/nations/presets/*.json 并返回给前端。
|   |   `-- PlayerNationApi.java  # **玩家国家 API**：封装玩家国家 list/get/save 的请求解析与响应序列化。
|   `-- newgame/                # **新游戏流程 API**：三步新游戏流程（选择国家/世界设置/确认创建）。
|       |-- NewGameApi.java     # **新游戏 API 逻辑**：step1/step2/step3 的处理逻辑，并在 step3 创建并启动 `StarAxisGameRuntime`。
|       |-- NewGameDraft.java   # **新游戏草稿模型**：保存新游戏流程的中间状态（nationId/worldGenConfig 等）。
|       |-- NewGameDraftFiles.java # **新游戏草稿路径工具**：统一管理草稿落盘目录与文件名（gamedata/saves/<username>_newgame.json）。
|       `-- NewGameDraftRepository.java # **新游戏草稿仓库**：新游戏草稿的文件读写（含所有权校验）。
|
|-- dto/                        # **网络 DTO**：面向前端/网络传输的只读数据结构（JSON 序列化）。
|   |-- DailySettlementStateDto.java # **每日结算 DTO**：对应每日结算快照的精简字段（settledDay/sectorCount）。
|   |-- RealTimeStateDto.java   # **实时状态 DTO**：包含 tick/时间/世界半径、星区中心点与实体快照列表。
|   |-- SectorCenterDto.java    # **星区中心点 DTO**：星区坐标(q,r)与其世界坐标(x,y)（GU）。
|   `-- SnapshotMessageDto.java # **快照消息顶层 DTO**：发送给前端的 snapshot 消息结构（ok/error/tickCostMs/realTime/daily）。
|
|-- game/                       # **游戏会话（进程内）**：webnet 进程内持有/管理运行中的游戏运行时（当前为单世界）。
|   `-- GameSessions.java       # **运行时存储**：保存当前全局 `StarAxisGameRuntime`（set/get/has）。
|
|-- repo/                       # **数据仓库**：负责特定领域数据的持久化读写（当前为本地文件）。
|   `-- nation/                 # **国家数据仓库**：玩家自定义国家的所有权校验与文件读写。
|       |-- AccountOwnershipValidator.java # **账号所有权校验器**：根据 username+playerId 校验 gamedata/accounts 文件，防止越权。
|       `-- PlayerNationFileRepository.java # **玩家国家文件仓库**：读写 gamedata/nations/players/<username>/<nationId>.json。
|
|-- response/                   # **响应结构（旧/兼容）**：特定接口的响应 DTO（部分已被 snapshot 消息替代）。
|   `-- RealTimeSnapshotResponse.java # **实时快照响应 DTO**：实时世界快照的顶层响应结构（扁平实体列表）。
|
`-- websocket/                  # **WebSocket 消息**：WS 推送消息的构造与封装。
    `-- SnapshotMessageFactory.java # **快照消息工厂**：从 `StarAxisGameRuntime` 构建 SnapshotMessageDto（含 sectorCenters/daily）。
