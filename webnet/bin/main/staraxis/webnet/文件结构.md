webnet/src/main/java/staraxis/webnet
|-- WebNetLauncher.java         # **启动入口（main）**：解析命令行参数，启动 Undertow 服务器并尝试打开浏览器喵。
|-- WebNetServer.java           # **核心服务端**：集成 Undertow HTTP/WebSocket 服务，挂载所有路由，驱动游戏模拟循环并广播快照，处理视野订阅消息喵。
|-- 文件结构.md                  # 本文件：提供 webnet 模块的逐文件枚举与职责索引喵。
|
|-- ai/                         # **AI 助手模块**：负责外部 AI Agent 的接入与生命周期管理喵。
|   |-- AiChatApi.java          # **AI 聊天接口**：提供与 AI 助手对话的 HTTP 路由处理喵。
|   |-- AiConfigApi.java        # **AI 配置接口**：管理 AI 模型参数与接入配置的 HTTP 路由喵。
|   |-- AiUsageApi.java         # **AI 用量接口**：统计并查询 AI Token 消耗与额度的 HTTP 路由喵。
|   |-- WebAiAutoStarter.java   # **AI 自动启动器**：根据前端活动状态自动管理 AI 进程的拉起与销毁喵。
|   `-- WebAiWebSocketHandler.java # **AI WS 处理器**：实现 /ws/ai 握手、鉴权以及基于玩家权限的工具调用（Tool Call）协议喵。
|
|-- api/                        # **业务 API 处理器**：按功能域组织的 HTTP 请求处理逻辑喵。
|   |-- I18nApi.java            # **国际化 API**：合并本体与 Mod 语言包，提供多语言字符串索引喵。
|   |-- ShipApi.java            # **舰船 API**：提供舰船纹理列表与设计器相关数据的 HTTP 接口喵。
|   |-- nation/                 # **国家 API 子包**喵。
|   |   |-- NationPresetsApi.java # **预设国家接口**：读取并返回游戏内置的预设国家配置喵。
|   |   `-- PlayerNationApi.java  # **玩家国家接口**：处理自定义国家的列表查询、获取与保存逻辑喵。
|   `-- newgame/                # **新游戏流程子包**喵。
|       |-- NewGameApi.java     # **新游戏主接口**：处理创建流程的三步走逻辑（选择、设置、确认）喵。
|       |-- NewGameDraft.java   # **流程草稿模型**：在内存中暂存新游戏创建过程中的中间配置数据喵。
|       |-- NewGameDraftFiles.java # **草稿路径工具**：定义新游戏草稿在磁盘上的存储路径规则喵。
|       `-- NewGameDraftRepository.java # **草稿持久化仓库**：实现新游戏草稿的 JSON 文件读写喵。
|
|-- auth/                       # **认证与会话管理**：处理登录、注册与玩家身份校验喵。
|   |-- AccountFiles.java       # **账号文件工具**：管理本地账号数据目录结构喵。
|   |-- AuthApi.java            # **认证路由处理**：提供 /api/auth 下的登录、注册、注销等接口实现喵。
|   `-- AuthStore.java          # **会话与账号仓库**：执行密码加密校验、维护 Token 与 Session 的内存映射喵。
|
|-- command/                    # **命令转换系统**：将网络指令转换为游戏引擎可执行命令喵。
|   |-- SetSimTimeSpeedCommand.java # **时间设置指令**：处理前端发来的游戏模拟速度调整请求喵。
|   |-- WebCommandHandler.java  # **命令处理器接口**：统一定义 Web 指令的处理契约喵。
|   `-- WebCommandRegistry.java # **指令注册表**：通过消息 type 分发 WebSocket 命令到对应的处理器喵。
|
|-- core/                       # **底层基础设施**：配置、日志、连接管理与静态路由喵。
|   |-- AdminApi.java           # **管理监控 API**：提供连通性测试、停机与重启等管理操作喵。
|   |-- WebNetLog.java          # **服务端日志记录**：将 webnet 运行日志写入 gamedata/logs/webnet.log 喵。
|   |-- WebNetServerConfig.java # **服务器运行配置**：封装 host、port、自动退出时间等启动参数喵。
|   |-- WebUiRoutes.java        # **WebUI 静态路由**：配置 Undertow 以托管前端静态资源喵。
|   `-- WsConnectionManager.java # **连接管理器**：维护活跃的 WebSocket 会话，记录每个连接的视野星区订阅状态喵。
|
|-- dto/                        # **数据传输对象**：面向网络传输的扁平化只读模型（JSON 序列化）喵。
|   |-- DailySettlementStateDto.java # **日结算 DTO**：封装具有结算周期特征的经济/人口数据模型喵。
|   |-- RealTimeStateDto.java   # **实时状态 DTO**：封装当前 Tick 的实体快照、时间与地理信息喵。
|   |-- SectorCenterDto.java    # **星区中心 DTO**：表示单个六边形星区在世界坐标系中的定位喵。
|   |-- SnapshotMessageDto.java # **顶级快照消息**：封装 WebSocket 推送给前端的完整世界快照包喵。
|   `-- WorldSummaryDto.java    # **世界综述 DTO**：包含全星系宏观统计信息的汇总数据喵。
|
|-- game/                       # **进程内引擎状态**喵。
|   `-- GameSessions.java       # **运行时持有者**：在 Web 服务中管理当前活跃的游戏引擎实例（StarAxisGameRuntime）喵。
|
|-- mod/                        # **Mod 管理系统**：处理外部扩展内容的加载顺序与启用逻辑喵。
|   |-- ModManager.java         # **Mod 核心管理**：扫描磁盘目录、计算加载顺序并导出已启用的 Mod 列表喵。
|   |-- ModMetadata.java        # **Mod 元数据模型**：对应 mod.json 的结构，包含作者、版本、兼容性信息喵。
|   |-- ModOrder.java           # **加载顺序配置**：封装 mod-order.json 序列化结构的内部模型喵。
|   |-- ModOrderRepository.java # **顺序配置仓库**：负责 mod-order.json 文件的读取与落盘喵。
|   `-- ModsApi.java            # **Mod 路由处理**：提供列表查询、顺序调整与禁用设置的 HTTP 接口喵。
|
|-- repo/                       # **持久化仓库层**：处理业务数据的存储细节喵。
|   `-- nation/                 # **国家存储子包**喵。
|       |-- AccountOwnershipValidator.java # **所有权校验器**：确保玩家只能读写属于自己的自定义国家数据喵。
|       `-- PlayerNationFileRepository.java # **国家文件仓库**：实现自定义国家在本地文件系统的 JSON 存储喵。
|
|-- response/                   # **旧版兼容响应包**（计划清理）喵。
|   `-- RealTimeSnapshotResponse.java # **快照响应结构**：旧版实体列表传输结构，正逐步被 snapshot 消息替代喵。
|
`-- websocket/                  # **WebSocket 消息构造**喵。
    `-- SnapshotMessageFactory.java # **快照工厂**：将游戏引擎的权威原始数据按需过滤并转换为 DTO，支持视野范围裁剪喵。
