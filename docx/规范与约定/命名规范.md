# 命名规范（项目通用规则）

> 👉 若需查看术语中英文对应，请跳转至《[术语表](术语表.md)》。

> 目标：统一代码 / 数据 / 配置的命名风格，降低歧义，提升可读性。

---

## 1. 总原则

- **标识符必须为英文**（禁止拼音）。
- **语义清晰优先**：宁可长一些，也不要随意缩写。
- **保持一致性**：同一概念在全项目中只能有一个英文名。

---

## 2. 大小写与命名风格

| 适用场景           | 风格            | 示例                     |
|--------------------|-----------------|--------------------------|
| 变量 / 函数        | `camelCase`     | `userProfile`, `calcSum` |
| 类 / 接口 / 组件   | `PascalCase`    | `UserService`, `AuthAPI` |
| 常量               | `UPPER_SNAKE_CASE` | `MAX_PAGE_SIZE`, `PI` |
| 文件 / 文件夹      | `kebab-case`    | `user-service`, `api-v2` |

*若目录或文档需要中文命名，可酌情使用，但代码目录仍建议采用 `kebab-case`。*

---

## 3. 禁止项

- **拼音**：如 `xingQuId`、`shouyi`。
- **过度缩写**：如 `cfgMgr`, `ecoSys`（除非全项目统一约定）。
- **同义不同名**：同一含义出现多个英文表达，例如同时使用 `user`、`player` 指代同一概念。

---

## 4. 文档字段注释规范

> 目标：让任意单篇文档即可自洽，读者无需跳转即可理解字段 / 结构 / 缩写含义。

### 4.1 适用范围

- 适用于所有开发文档（总览、系统设计、协议、示例、缺口清单等）。
- “字段 / 代码名”包括但不限于：
  - 协议字段：`cmdId`, `clientSeq`, `serverTick`
  - 结构名：`RequestHeader`, `RequestAck`, `AuditEvent`
  - 枚举 / 状态码：`Rejected`, `Timeout`
  - 关键集合 / 变量：`pendingTasks`, `processedIds`

### 4.2 正文写法（行内字段必须注释）

- 在正文出现字段 / 结构名时，必须采用以下格式之一：
  - **推荐**：`fieldName`（一句话解释它是什么或做什么用）
  - 或：`fieldName`（是什么）+（作用 / 维护者）

示例：

- `clientSeq`（客户端递增序号，用于乱序 / 丢包检测）
- `serverTick`（服务器权威 tick，用于联机对齐与预测回滚）

### 4.3 代码块写法（每个字段行内注释）

```ts
interface CommandHeader {
  cmdId: string;      // 指令全局唯一 ID，用于幂等 / 去重
  clientSeq: number; // 客户端递增序号
  serverTick: number; // 权威 tick
}
```

### 4.4 枚举 / 状态码写法

- 枚举值必须附带中文解释：
  - `Timeout`（请求超时）
  - `Unauthorized`（未认证）

### 4.5 例外情况（应极少出现）

- 众所周知的通用缩写可不解释（如 CPU、GPU、JSON）。
- 大段“完整字段表”可将解释移入表格，但需保证同页可见。

## 5. 通用示例（≥ 20）

以下示例仅供参考，覆盖常见领域，均采用前述风格：

1. `userId`（用户 ID）
2. `orderId`（订单 ID）
3. `createdAt`（创建时间戳）
4. `updatedAt`（更新时间戳）
5. `isActive`（是否启用）
6. `maxRetryCount`（最大重试次数）
7. `requestTimeoutMs`（请求超时毫秒数）
8. `priceCents`（价格，单位分）
9. `discountRate`（折扣率）
10. `calculateTotal()`（计算总价）
11. `UserController`（用户控制器）
12. `AuthService`（认证服务）
13. `PaymentGateway`（支付网关）
14. `onUserLogin`（用户登录事件）
15. `fetchUserProfile()`（拉取用户资料）
16. `MAX_PAGE_SIZE`（分页最大条数）
17. `DEFAULT_LANGUAGE`（默认语言）
18. `file-path-utils`（文件路径工具包）
19. `emailValidator`（邮箱校验器）
20. `reportGenerationJob`（报表生成任务）
21. `isPendingApproval`（是否待审批）
22. `SessionExpired`（会话过期枚举值）
23. `parseJsonSafe()`（安全解析 JSON）
24. `CacheProvider`（缓存提供者接口）
25. `errorHandlingMiddleware`（错误处理中间件）
