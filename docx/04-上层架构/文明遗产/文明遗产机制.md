# 文明遗产机制（隐藏机制）

> 目标：定义一个独特的、跨游戏存档的“文明遗产”系统，使得玩家在每一局游戏中的成就，能够转化为下一局游戏中的探索内容，增加游戏的长期可玩性和叙事深度。

## 1. 核心理念

- **循环叙事**：玩家的每一次游戏都不是孤立的。他们曾经建立的辉煌帝国，其遗迹可能会在未来的宇宙中被新的文明（甚至是玩家自己）所发现。
- **非对称开局**：通过在宇宙中散布这些强大的“文明遗产”，为新游戏创造独特的、非对称的探索热点和战略机遇。

---

## 2. 保存阶段：创建遗产

### 2.1 触发时机

- 在一局游戏**结束时**（无论是胜利、失败还是主动选择“结束游戏”），系统会触发“文明遗产”的保存流程。

### 2.2 选择与转换

系统会**随机地**从玩家本局游戏中选择一部分最有价值的资产，并将其转换为“遗产模板”，存入一个全局的“遗产池”中。

- **可被选择的内容**：
  1.  **星区布局**：随机选择1-3个玩家最发达的星区。保存其恒星系结构、行星类型、城市发展水平和独特的行星地貌。
  2.  **舰船设计**：随机选择1-3个玩家最强大或最常用的舰船设计蓝图。

- **转换过程**：
  - 保存的数据会被“做旧”，例如，星区会被标记为“古代遗迹”，舰船设计会成为“失落的蓝图”。

### 2.3 遗产数据结构（口径）

```typescript
// 概念性数据结构
interface HeritageSiteTemplate {
  id: string;
  type: 'Sector' | 'ShipBlueprint';
  originalEmpireName: string; // 来源帝国的名称
  savedAt: Date; // 保存时间
  data: any; // 具体的数据，如星区布局或舰船蓝图
}
```

---

## 3. 生成阶段：注入遗产

### 3.1 触发时机

- 在**新游戏的世界生成**阶段。

### 3.2 生成参数

- 世界生成参数 `worldGenConfig` 中应包含一个 `heritageInjectionRatio`，用于控制从“遗产池”中抽取多少遗产注入到新宇宙中。

### 3.3 生成行为

1.  世界生成器根据 `heritageInjectionRatio`，从全局“遗产池”中随机抽取若干个 `HeritageSiteTemplate`。
2.  将这些遗产模板作为特殊的“兴趣点”或“异常”放置到新生成的宇宙地图中。
    -   **星区遗产**：可能会生成一个被强大远古防御系统守护的、拥有高度发达城市的恒星系。
    -   **舰船遗产**：可能会生成一个包含古代舰船残骸的特殊异常点。

---

## 4. 探索与奖励

### 4.1 发现与探索

- 玩家需要通过派遣**科研船**或**舰队**来探索这些特殊的“文明遗产”点。
- 探索过程可能会触发一系列独特的**事件链**，讲述这个失落文明的故事。

### 4.2 奖励类型

成功完成探索后，玩家可以获得丰厚且独特的奖励：

- **独特科技**：获得一项当前科技树中没有的、甚至是“逆向工程”得来的稀有科技。
- **特殊舰船/模块蓝图**：直接获得一个强大的、无法通过常规研究解锁的舰船设计或模块。
- **大量资源**：获得一笔可观的稀有资源或基础资源。
- **永久帝国修正**：获得一个对整个帝国生效的永久性加成（Modifier）。
