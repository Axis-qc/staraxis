# 科研机制

> 目标：定义科研点数的产生、分配和科技研究流程，核心围绕“1主推+2次级”的并行研究机制。

## 1. 科研产出 (Research Generation)

- **来源**：科研点数（Research Points）主要由**城市**（通过“科研城市”专精或特定建筑）和**太空设施**（如科研空间站）产出。
- **统一类型**：与之前的设计不同，现在只产出一种通用的**科研点数**，不再按领域（物理/社会/工程）区分。这简化了经济管理，将策略重心放在科技的选择上。
- **领袖加成**：负责科研的领袖（科学家）可以为总科研产出提供百分比加成。

## 2. 研究流程：“1主推 + 2次级”

### 2.1 选择主推科技

- 玩家可以从科技树中所有**当前可研究**（即所有前置科技都已完成）的科技中，**选择一个**作为**主推科技 (Primary Research)**。

### 2.2 自动选择次级科技

- 当玩家选定一个主推科技后，系统会自动从**其他可研究的科技**中，**随机选择两个**作为**次级科技 (Secondary Research)**。
- **目的**：模拟帝国在主攻一个方向的同时，其他领域的探索也在缓慢进行，增加研究的惊喜和适应性。
- **刷新机制**：次级科技在主推科技研究完成并选定新的主推科技后，会重新随机选择。

### 2.3 科研点数分配

- **主推科技**：获得 **100%** 的科研点数投入。
  `主推科技进度 += 每月总科研产出`

- **次级科技**：每个次级科技分别获得 **50%** 的科研点数投入。
  `次级科技1进度 += 每月总科研产出 * 0.5`
  `次级科技2进度 += 每月总科研产出 * 0.5`

### 2.4 研究完成

- 当任何一个科技（无论是主推还是次级）的 `当前研究进度` >= `其研究成本 (cost)` 时，该科技被视为研究完成。
- **效果**：
  1.  该科技解锁的效果立即对整个帝国生效。
  2.  该科技从科技树中标记为“已完成”。
  3.  **如果完成的是主推科技**：玩家需要重新选择一个新的主推科技。
  4.  **如果完成的是次级科技**：该研究槽位重新随机选择一个。

## 3. “溢出”机制 (Spillover)

- **概念**：当一个科技研究完成时，超出其成本的“溢出”科研点数，不会被浪费。
- **规则**：
  - 如果是**主推科技**完成，其溢出点数将按比例（例如50%）分配给**下一个被选定的主推科技**。
  - 如果是**次级科技**完成，其溢出点数将按比例（例如50%）**返还**到帝国的科研“缓冲池”中，用于下一个周期的分配。
