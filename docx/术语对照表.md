# 术语对照表

> 按来源模块归档。本批新增均来自 **服务端主循环** 最终敲定方案。
>
> 格式：`术语`（中文意思） / 具体作用 / 同义词或容易混淆的词

---

## 服务端主循环

- **baseDtGameHours**（基准游戏小时步长）/ 固定值 1/25 h，每 Tick 推进的基础游戏小时 / 与 `dtGameHours`（实际步长）易混
- **CancelCommand**（取消指令）/ 取消待执行指令的专用类型 / 与“删除指令历史”易混
- **clientSeq**（客户端递增序号）/ 用于乱序检测与稳定排序 / 与 `cmdId`（全局唯一）易混
- **cmdId**（指令全局唯一 ID）/ 幂等去重、回执对账键 / 与 `clientSeq`（递增序号）易混
- **Command**（客户端意图指令）/ 玩家意图的唯一载体，在服务端执行 / 与 `Event`（结果增量）易混
- **CommandAck**（指令回执）/ 服务端对 `Command` 的执行结果回执 / 与事件或快照回包易混
- **DailyAccumulator**（日内累计器）/ 统计本日发生的经济等指标，供结算用 / 与 `DailySnapshot`（结果账本）易混
- **dailyRef**（DailySnapshot 原子引用）/ 指向当前生效的 `DailySnapshot` / 与可变 `WorldState` 引用易混
- **DailySettlementDelta**（日结算增量）/ 将 Draft 应用到 `WorldState` 的可写差异集 / 与 `DailySettlementDraft`（只读计算产物）易混
- **DailySettlementDraft**（日结算草稿）/ 后台线程计算出的日结算只读结果 / 与 Delta（落账差异）易混
- **DailySettlementState**（日结算状态机）/ 草稿计算与落账阶段的状态枚举 / –
- **DailySnapshot**（上一日快照）/ 日结算完成后生成，供 UI 与经济系统读取 / 与 `RealtimeSnapshot`（实时快照）易混
- **dtGameHours**（实际游戏小时步长）/ `baseDtGameHours × timeScale`，各系统推进用 / 与 `tickBudgetMs`（性能预算）无关
- **eventBufferBytesCap**（事件缓冲字节上限）/ 事件环形缓冲占用内存硬上限 / –
- **eventBufferWindowTicks**（追帧窗口覆盖 Tick 数）/ 环形缓冲可追帧的 Tick 长度 / 与“现实秒数窗口”易混
- **eventDefId**（事件定义 ID）/ 指向事件配置表的键 / 与 `eventInstanceId`（实例）易混
- **eventInstanceId**（事件实例唯一 ID）/ 交互事件实例主键 / –
- **eventSeqInTick**（Tick 内事件序列号）/ 保证同 Tick 内事件顺序确定 / 与跨 Tick 顺序易混
- **Event**（权威事件）/ 权威变更增量，供客户端追帧 / 与 `Command`（输入意图）易混
- **Event Ring Buffer**（事件环形缓冲）/ 最近 N Tick 的事件缓存，用于追帧 / 与 `Interactive Event Store`（交互事件存储）易混
- **gameDatetimeDay**（游戏日序号）/ 记录自开局以来的累计“游戏日”，日结算与账本归档的主键 / 与现实日历日期易混
- **groupKey**（可覆盖指令分组键）/ 对可覆盖型指令取代旧指令 / 与 `cmdId`（唯一）易混
- **Interactive Event Store**（交互事件存储）/ 存放需玩家操作事件的仓库 / 与事件环形缓冲易混
- **InteractiveEventInstance**（交互事件实例）/ 需要玩家选择的事件实体 / –
- **localTimeScale**（实体局部时间倍率）/ 个体实体的局部时间倍率，可与全局不同 / 与 `timeScale`（全局）易混
- **maxCommandsPerTick**（每 Tick 处理指令上限）/ 防止计算爆炸 / –
- **maxCommandsPerTickPerAi**（每 AI 每 Tick 指令上限）/ AI 指令限流 / 与玩家限流易混
- **maxCommandsPerTickPerPlayer**（每玩家每 Tick 指令上限）/ 玩家指令限流 / 与 AI 限流易混
- **maxEventsPerTick**（单 Tick 事件上限）/ 防止事件风暴 / –
- **Pending / Resolved / Expired**（交互事件状态）/ 交互事件生命周期枚举 / –
- **playerId**（玩家 ID）/ 指令归属与权限校验主键 / 与 `ownerPlayerId`（事件归属）易混
- **playerScale**（玩家调速倍率）/ 玩家在 UI 档位选择的倍率，合成 `timeScale` 的一因子 / 与系统强制上限易混
- **rawCap / rawCapClamped**（候选倍率 / 钳制倍率）/ 计算 `systemCapScale` 中间值 / –
- **RealtimeSnapshot**（实时快照）/ 高频实时态，用于战斗与态势 / 与 `DailySnapshot`（账本快照）易混
- **retainDays**（保留天数）/ 交互事件在存储中维持的游戏日数 / –
- **serverTick**（服务端权威 Tick）/ 世界唯一权威时间轴，用于联机对齐与推进 / 与客户端渲染帧或 wall-clock 时间易混
- **skillScale**（技能倍率）/ 单个时间类技能对应的全局减速倍率 / –
- **skillScaleGlobal**（全局技能倍率）/ 多个全局时间技能取最小值后的结果 / –
- **systemCapScale**（系统强制倍率上限）/ 由性能监控根据超预算情况给出，钳制最终 `timeScale` / 与 `playerScale`、`skillScaleGlobal` 角色不同
- **targetEntityId**（目标实体 ID）/ 指令针对的实体 / –
- **targetTicksPerSecond**（目标 Tick 频率）/ 默认 25，可在熔断模式下降低 / 与 `ticksPerSecond`（常量定义）易混
- **tickBudgetMs**（Tick 预算毫秒）/ 目标 wall-clock 耗时；25tick/s ⇒ 40ms / 与 `dtGameHours`（游戏时间步长）易混
- **tickCostMs**（Tick 实际耗时）/ 当前 Tick 真实 wall-clock 耗时 / –
- **tickInDay**（当日 Tick 计数）/ 记录当前游戏日已推进的 Tick 数，用于跨日触发点 / 与 `serverTick`（全局）易混
- **ticksPerDay**（每日 Tick 数）/ 常量；24h × 25tick = 600，用于判断跨日 / 与上游调频时的 `ticksPerDayDynamic` 概念易混
- **timeScale**（全局时间倍率）/ 决定世界基础推进速度；现实 1 秒推进 `timeScale` 小时 / 与 `systemCapScale`（上限）易混
- **timeScaleBase**（基础合成倍率）/ `playerScale × skillScaleGlobal` 结果 / 与最终 `timeScale`（被系统上限钳制）易混
- **WorldState**（权威世界状态对象图）/ 服务端内存中的权威数据对象集合 / 与快照（Snapshot）易混
