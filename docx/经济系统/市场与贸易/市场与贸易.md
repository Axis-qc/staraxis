# 市场与贸易

> 目标：定义行星市场与星际市场的概念边界、价格机制和自动化交易规则。

## 1. 行星市场（Planet Market）

- **范围**：每个星球拥有独立的市场，处理本星球的内部供需和对外贸易请求。
- **核心功能**：根据库存水平，自动生成出口（卖出）和进口（买入）订单。

### 1.1 自动进出口规则（口径）

为每个资源定义库存阈值，以驱动自动贸易：

- **出口触发**：当某资源的 `当前库存` > `出口阈值` (例如，仓库容量的80%) 时，将超出部分的盈余挂单到星际市场等待出售。
- **进口触发**：当某资源的 `当前库存` < `进口阈值` (例如，仓库容量的20%) 时，生成一个进口订单，从星际市场购买短缺的部分。
- **优先级**：本地的生产和消耗结算**优先于**进出口。一个结算周期内，必须先满足本地所有消耗，有剩余才能用于出口。

## 2. 星际市场（Interstellar Market）

- **功能**：一个全局的订单簿，汇总所有行星市场的进出口订单，并进行撮合交易。
- **交易类型**：
  - **常规贸易**：由行星市场自动生成的进出口订单。
  - **国家间合约**：玩家之间签订的长期、固定价格的贸易协定。

## 3. 价格机制（口径）

### 3.1 动态价格公式

采用动态价格公式来模拟市场波动：

`price = basePrice * (1 + (totalDemand - totalSupply) / (totalDemand + totalSupply))`

- **`basePrice`**：该资源在数据表中定义的基础价格。
- **`totalDemand`**：星际市场上所有该资源的**买单**总量。
- **`totalSupply`**：星际市场上所有该资源的**卖单**总量。

### 3.2 极端情况处理

- **当 `totalSupply` 为 0 时**（极端短缺）：为避免价格无限上涨，价格将被限制在一个上限，例如 `price = basePrice * 10`。
- **当 `totalDemand` 为 0 时**（极端过剩）：为避免价格跌至零或负数，价格将被限制在一个下限，例如 `price = basePrice * 0.1`。

> 注：本文档给出口径与公式形式，具体的 `basePrice`、阈值百分比、价格上下限乘数等均为数据驱动的参数。
