# 交互分层（视角层级与信息密度）

> 目标：统一不同缩放层级下“看什么/不看什么/能点什么”，并明确 UI 与逻辑的责任边界。

## 1. 总原则

- 同一对象在不同层级下位置必须一致，仅改变“显示细节”和“可交互内容”。
- UI 层独立：UI 不做规则计算，只展示与转发输入。

## 2. 行星地表视角（Planet Surface View）

- **显示对象**：行星上的**城市列表**、**地表特征**（如大陆、海洋的轮廓和名称）、行星级设施（如行星护盾）。
- **交互**：**建立新城市**（在允许的地表特征上）、**选择并进入城市管理界面**。
- **摘要信息**：行星总人口、总住房、总岗位数、总资源产出/消耗、宜居性、行星大小等核心属性。

## 3. 恒星系内部视角（Star System View）

- **显示对象**：恒星/行星/卫星/轨道建筑/舰船轨迹。
- **交互**：舰队移动、战斗指令、轨道建筑建造、选择行星进入地表视角。
- **摘要信息**：行星摘要（如人口、开发规模）、舰队补给、轨道设施状态。

## 4. 星区/星域视角（Sector/Region View）

- **显示对象**：六边形星区单元、星云/风暴/深空标记、关键节点。
- **交互**：选择星区、规划航道/补给线、查看星区摘要。
- **摘要信息**：星区类型、重要建筑、舰队数量摘要。

## 5. 银河/宇宙视角（Galaxy/Universe View）

- **显示对象**：银河级势力范围、宏观 POI、星域轮廓。
- **交互**：导航、外交/战略决策入口。
- **摘要信息**：势力范围、宏观统计。

## 6. 验收场景（示例）

- **Given** 玩家在恒星系视角，**When** 选择一个已殖民行星并进入地表视角，**Then** 玩家能看到该行星上的城市列表和地表特征，并可以进行城市管理。
