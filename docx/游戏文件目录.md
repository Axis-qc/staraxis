## 规划目录（服务端源码结构，待落地）

> 说明：本节为**规划目录**（用于指导后续落地实现），不代表当前仓库已存在。
> 
> 设计目标：
> - 主循环极简：仅负责权威时间、冻结输入、调度模块、串行落账、产物发布。
> - 逻辑下沉：经济/战斗/AI/事件等全部在模块内实现，通过接口挂载到主循环。
> - 可演进：网络、存储、模块、协议可独立扩展；共享协议可复用到客户端。
>
```text
staraxis/
├── server/                          # 服务端（规划：权威模拟、联机、存储）
│   ├── build.gradle                 # 服务端模块构建脚本（规划）
│   └── src/main/java/io/staraxis/server/
│       ├── ServerMain.java          # 服务端进程入口（解析参数、启动组件）
│       │
│       ├── loop/                    # 主循环（极简）
│       │   ├── ServerLoop.java      # Tick 循环调度器（Prepare/Update/Commit/PostUpdate）
│       │   ├── TickContext.java     # Tick 上下文（serverTick/timeScale/dtGameHours 等）
│       │   ├── TickInput.java       # 冻结输入（本 tick commands 等）
│       │   ├── TickOutput.java      # 模块产物聚合（candidates/events/acks 等）
│       │   ├── PerfController.java  # tickCostMs 监控 + systemCapScale 控制（时间膨胀/熔断）
│       │   └── TickScheduler.java   # wall-clock 调度（25 tick/s + 熔断降频）
│       │
│       ├── module/                  # 模块化接口与模块注册
│       │   ├── IGameModule.java     # 模块接口（onPrepare/onUpdate/onCommit/onPostUpdate）
│       │   ├── ModuleRegistry.java  # 模块注册与固定顺序（phaseOrder）
│       │   └── modules/             # 具体业务模块（示例）
│       │       ├── combat/          # 战斗模块
│       │       ├── economy/         # 经济模块
│       │       ├── ai/              # AI 模块
│       │       ├── event/           # 事件模块（含交互事件）
│       │       └── movement/        # 移动/航行模块
│       │
│       ├── world/                   # 权威世界数据（只允许主循环写）
│       │   ├── WorldState.java      # 权威世界状态对象图/表结构
│       │   ├── rng/                 # 确定性 RNG
│       │   └── index/               # 各类索引（可在快照构建期派生）
│       │
│       ├── command/                 # 指令队列与口径
│       │   ├── CommandQueue.java    # pendingByPlayer/冻结输入/排序/限流/round-robin
│       │   ├── CommandValidator.java# 权限/参数/状态校验（执行前）
│       │   └── CommandAckBus.java   # 回执收集（PostUpdate 统一下发）
│       │
│       ├── net/                     # 网络边界（连接管理/可靠层/打包）
│       │   ├── ingress/             # 入站：解包/鉴权/幂等去重/推入入口队列
│       │   ├── outbox/              # 出站：事件/快照/回执消息队列
│       │   ├── codec/               # 编解码（protobuf/json/自定义）
│       │   └── session/             # 会话与连接状态
│       │
│       ├── snapshot/                # 快照（只读、跨线程安全）
│       │   ├── RealtimeSnapshot.java# 实时快照（高频）
│       │   ├── DailySnapshot.java   # 日快照（UI 只读）
│       │   ├── SnapshotBuilder.java # 基于 WorldState 构建快照
│       │   └── InterestCulling.java # 兴趣范围裁剪
│       │
│       ├── eventlog/                # 事件日志与追帧
│       │   ├── Event.java           # 权威事件
│       │   ├── EventRingBuffer.java # 事件环形缓冲（追帧窗口）
│       │   └── EventChunker.java    # 分包/退化快照策略
│       │
│       ├── settlement/              # 日结算（并行 Draft + 主循环 Commit）
│       │   ├── DailyAccumulator.java        # 日内累计器（主循环写）

│       │   └── DailySettlementService.java  # trigger/tryCommitIfReady
│       │
│       ├── store/                   # 持久化与存档（规划：可选）
│       │   ├── SaveService.java     # 存档服务（落盘 I/O）
│       │   └── ReplayService.java   # 回放/对账
│       │
│       └── util/                    # 工具（结构化日志、统计等）
│
├── shared/                          # 共享协议与通用结构（规划：客户端/服务端复用）
│   ├── build.gradle                 # 共享模块构建脚本（规划）
│   └── src/main/java/io/staraxis/shared/
│       ├── protocol/                # 协议（Command/Event/Snapshot DTO）
│       ├── ids/                     # ID 类型与校验
│       └── math/                    # 定点/量化口径（若需要）
│
└── client/                          # 客户端（规划：若未来拆分模块）
    └── ...
```
