# StarAxis 项目目录结构

> 目标：设计实际可落地项目结构
> 
> 说明：本文件已于 2026-01-14 更新，以反映项目迁移到 `core/client/server/shared` 多模块结构并缩短包名后的最终状态。

```text
# StarAxis 游戏开发目录结构

staraxis/
├── assets/                          # 游戏资源（所有模块共享）
│   ├── effect/                     # 特效资源
│   │   ├── PNG (Black background)/ # 特效 PNG（黑底）
│   │   └── PNG (Transparent)/      # 特效 PNG（透明底）
│   ├── fonts/                      # 字体文件
│   │   ├── AlibabaPuHuiTi-3-65-Medium.ttf  # 阿里巴巴普惠体
│   │   └── NotoSansSC-Regular.ttf  # 思源黑体（简体中文）
│   ├── ui/                         # UI 资源（客户端/工具共享，非代码）
│   │   └── staraxis/               # 项目自有 UI 资源根目录
│   │       ├── atlas/              # UI 图集（.atlas/.png）
│   │       ├── fonts/              # UI 位图字体（.fnt/.png）
│   │       ├── skin/               # UI 皮肤（Skin.json / 主题配置）
│   │       └── layouts/            # UI 布局数据（若后续走数据驱动）
│   └── world/                      # 世界/背景资源
│
├── shared/                          # 共享模块（协议/模型，客户端与服务端复用）
│   ├── build.gradle                 # shared 模块构建脚本
│   └── src/main/java/staraxis/shared/ # shared 源码根目录（目前为空，待填充协议/DTO/通用类型）
│
├── core/                            # 核心逻辑模块（严格无平台依赖）
│   ├── build.gradle                 # core 模块构建脚本
│   └── src/main/java/staraxis/core/   # core 源码根目录（目前为空，待填充纯逻辑代码）
│
├── client/                          # 客户端模块（UI/渲染/同步/入口）
│   ├── build.gradle                 # client 模块构建脚本
│   └── src/main/java/staraxis/      # client 顶层包（客户端入口与实现）
│       ├── ClientGame.java          # 客户端游戏主入口（实现 ApplicationListener）
│       ├── UiPreviewApp.java        # UI 预览入口（仅渲染 UI，不跑世界）
│       └── client/                  # 客户端分层结构（实现细节按层归档）
│           ├── input/               # 输入采集与 Command 构建
│           │   ├── CommandBuilder.java  # 从玩家输入构建 Command DTO
│           │   └── InputProcessor.java  # 处理 GDX 输入事件
│           ├── net/                 # 网络层（连接/收发/编解码/可靠层）
│           │   ├── tcp/                 # TCP 控制通道（登录/握手/心跳/重连协商）
│           │   ├── udp/                 # UDP 数据通道（Commands/Events/Snapshots）
│           │   ├── reliable/            # UDP 可靠层（ack/重传/乱序/分片）
│           │   ├── session/             # 客户端会话管理
│           │   └── codec/               # 报文编解码
│           ├── sync/                # 同步层（事件追帧/快照切换/权威帧整理）
│           │   ├── authority/           # 权威帧（AuthorityFrame）定义
│           │   ├── catchup/             # 追帧与超窗退化快照逻辑
│           │   ├── interest/            # 兴趣范围（InterestSpec）请求与切换
│           │   ├── snapshot/            # 快照分片组装
│           │   └── event/               # 权威事件应用（按 serverTick+eventSeqInTick）
│           ├── sim/                 # 展示用模拟态（SimulatedState：只读展示模型）
│           │   ├── SimulatedState.java  # 只读世界状态（UI/渲染的数据源）
│           │   └── SimEntity.java       # 客户端侧实体对象（只读）
│           ├── render/              # 表现态与渲染辅助（RenderState：视觉预测/平滑）
│           │   ├── RenderState.java     # 渲染用状态（含预测值）
│           │   ├── Predictor.java       # 视觉预测（外推位置/朝向）
│           │   ├── Reconciler.java      # 对账与硬对齐（Correction Warp）
│           │   └── WorldRenderer.java   # 世界对象渲染
│           ├── ui/                  # UI 独立系统（面板/控件/视图模型）
│           │   ├── model/           # UI ViewModel（UI 数据入口/订阅）
│           │   ├── panel/           # UI 面板（经济/舰队/科技等）
│           │   └── widget/          # 可复用控件（按钮/列表/通用窗口等）
│           └── debug/               # 调试工具（日志/诊断/调试 UI）
│               ├── DebugPanel.java      # 调试面板
│               └── NetStatsDisplay.java # 网络统计显示
│
├── server/                          # 服务端模块（权威模拟/网络/存储）
│   ├── build.gradle                 # server 模块构建脚本
│   └── src/main/java/staraxis/server/ # server 源码根目录
│       ├── ServerMain.java          # 服务端进程入口（解析参数、启动组件）
│       │
│       ├── loop/                    # 主循环（极简调度器：Prepare/Update/Commit/PostUpdate）
│       │   ├── ServerLoop.java      # Tick 循环调度器（只负责调度与落账）
│       │   ├── TickContext.java     # Tick 上下文（serverTick/timeScale/dtGameHours 等）
│       │   ├── TickInput.java       # 冻结输入（本 tick commands 等）
│       │   ├── TickOutput.java      # 模块产物聚合（candidates/events/acks 等）
│       │   ├── PerfController.java  # tickCostMs 监控 + systemCapScale 控制（时间膨胀/熔断）
│       │   └── TickScheduler.java   # wall-clock 调度（25 tick/s + 熔断降频）
│       │
│       ├── time/                    # 模拟时间（V2：Tick 与游戏时间推进分离）
│       │   ├── TimeScaleComposer.java # timeScale 合成（player/skill/systemCap）
│       │   └── SimulationClock.java # serverTick/gameDatetimeDay/accGameHoursInDay 推进与跨日判定
│       │
│       ├── module/                  # 模块化接口与模块注册
│       │   ├── IGameModule.java     # 模块接口（onPrepare/onUpdate/onCommit/onPostUpdate）
│       │   ├── ModuleRegistry.java  # 模块注册与固定顺序（phaseOrder）
│       │   └── modules/             # 业务模块（战斗/经济/AI/事件等）
│       │
│       ├── world/                   # 权威世界数据（只允许主循环 Commit 写入）
│       │   ├── WorldState.java      # 权威世界状态对象图/表结构
│       │   ├── rng/                 # 确定性 RNG
│       │   └── index/               # 各类索引（快照构建期派生）
│       │
│       ├── command/                 # 指令管线（网络接入 -> 入队 -> 冻结 -> 执行 -> 回执）
│       │   ├── CommandQueue.java    # pendingByPlayer/冻结输入/排序/限流/round-robin
│       │   ├── CommandValidator.java# 权限/参数/状态校验
│       │   └── CommandAckBus.java   # CommandAck 收集（PostUpdate 统一下发）
│       │
│       ├── net/                     # 联机通讯系统（TCP 控制 + UDP 数据 + UDP 可靠层）
│       │   ├── tcp/                 # TCP 控制通道（登录/握手/心跳/重连协商/投票等）
│       │   ├── udp/                 # UDP 数据通道（Commands/Events/Snapshots）
│       │   ├── reliable/            # UDP 可靠层（packetSeq/ackBits/重传/乱序窗口/分片）
│       │   ├── session/             # PlayerSession 与会话管理（udpRemote 绑定等）
│       │   ├── codec/               # 编解码（Protobuf/CRC32 等）
│       │   ├── ingress/             # 入站管线（解包/校验/幂等/入队）
│       │   └── outbox/              # 出站队列（事件/快照/回执分发与优先级）
│       │
│       ├── snapshot/                # 快照（InterestSnapshot / WorldSnapshot）
│       │   ├── RealtimeSnapshot.java# 实时快照（高频，对外同步）
│       │   ├── DailySnapshot.java   # 日快照（UI 只读账本态）
│       │   ├── SnapshotBuilder.java # 基于 WorldState 构建快照
│       │   └── InterestCulling.java # 兴趣范围裁剪（InterestSpec）
│       │
│       ├── eventlog/                # 事件日志与追帧（EventRingBuffer）
│       │   ├── Event.java           # 权威事件（必须含 serverTick/eventSeqInTick 等）
│       │   ├── EventRingBuffer.java # 环形缓冲（追帧窗口）
│       │   └── EventChunker.java    # 分包与退化快照策略（超窗/过大/发送失败）
│       │
│       ├── settlement/              # 日结算（并行 Draft + 主循环 Commit）
│       │   ├── DailyAccumulator.java        # 日内累计器（主循环写）
│       │   ├── DailySettlementJobInput.java # 结算输入快照（只读）
│       │   ├── DailySettlementDraft.java    # 并行草稿（不可变）
│       │   ├── DailySettlementState.java    # 状态机
│       │   └── DailySettlementService.java  # trigger/tryCommitIfReady
│       │
│       ├── store/                   # 持久化与存档（可选：WorldSnapshot 落盘/加载）
│       │   ├── SnapshotStore.java   # 快照清单/分片存储（manifest+chunk）
│       │   └── SaveService.java     # 存档服务（落盘 I/O）
│       │
│       └── util/                    # 工具（结构化日志、监控指标等）
│
├── lwjgl3/                           # 桌面端启动壳（仅平台相关）
│   ├── build.gradle                 # 桌面端打包/运行配置（workingDir 指向 assets）
│   └── src/main/java/staraxis/lwjgl3/ # 桌面端启动代码包
│       ├── Lwjgl3Launcher.java      # 桌面启动器（创建 Lwjgl3Application(new ClientGame(), ...)）
│       ├── UiPreviewLauncher.java   # UI 预览启动器（创建 Lwjgl3Application(new UiPreviewApp(), ...)）
│       └── StartupHelper.java       # 启动辅助（macOS -XstartOnFirstThread 等）
│
├── .specify/                        # 开发规范（IDE/流程/模板等）
│
├── build.gradle                     # 根项目构建配置
├── gradle.properties                # Gradle 属性（版本号等）
└── settings.gradle                  # Gradle 模块配置（include：core/client/server/shared/lwjgl3）
```

## 关键入口文件

- **桌面端启动入口**：`lwjgl3/src/main/java/staraxis/lwjgl3/Lwjgl3Launcher.java`
- **UI 预览启动入口**：`lwjgl3/src/main/java/staraxis/lwjgl3/UiPreviewLauncher.java`
- **客户端游戏主类**：`client/src/main/java/staraxis/ClientGame.java`

---

## 模块依赖关系（最终）

- `shared`：不依赖任何模块
- `core`：可依赖 `shared`
- `client`：依赖 `core` + `shared`
- `server`：依赖 `core` + `shared`
- `lwjgl3`：依赖 `client`
