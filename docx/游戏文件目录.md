> 说明：本文件已于 2026-01-14 更新，以反映项目迁移到 `core/client/server/shared` 多模块结构并缩短包名后的最终状态。

```text
# StarAxis 游戏开发目录结构

staraxis/
├── assets/                          # 游戏资源（所有模块共享）
│   ├── effect/                     # 特效资源
│   │   ├── PNG (Black background)/ # 特效 PNG（黑底）
│   │   └── PNG (Transparent)/      # 特效 PNG（透明底）
│   ├── fonts/                      # 字体文件
│   │   ├── AlibabaPuHuiTi-3-65-Medium.ttf  # 阿里巴巴普惠体
│   │   └── NotoSansSC-Regular.ttf  # 思源黑体（简体中文）
│   ├── ui/                         # UI 资源（客户端/工具共享，非代码）
│   │   └── staraxis/               # 项目自有 UI 资源根目录
│   │       ├── atlas/              # UI 图集（.atlas/.png）
│   │       ├── fonts/              # UI 位图字体（.fnt/.png）
│   │       ├── skin/               # UI 皮肤（Skin.json / 主题配置）
│   │       └── layouts/            # UI 布局数据（若后续走数据驱动）
│   └── world/                      # 世界/背景资源
│
├── shared/                          # 共享模块（协议/模型，客户端与服务端复用）
│   ├── build.gradle                 # shared 模块构建脚本
│   └── src/main/java/staraxis/shared/ # shared 源码根目录（目前为空，待填充协议/DTO/通用类型）
│
├── core/                            # 核心逻辑模块（严格无平台依赖）
│   ├── build.gradle                 # core 模块构建脚本
│   └── src/main/java/staraxis/core/   # core 源码根目录（目前为空，待填充纯逻辑代码）
│
├── client/                          # 客户端模块（UI/渲染/同步/入口）
│   ├── build.gradle                 # client 模块构建脚本
│   └── src/main/java/staraxis/      # client 顶层包（客户端入口与实现）
│       ├── ClientGame.java          # 客户端游戏主入口（实现 ApplicationListener）
│       ├── UiPreviewApp.java        # UI 预览入口（仅渲染 UI，不跑世界）
│       └── client/                  # 客户端分层结构（实现细节按层归档）
│           ├── input/               # 输入采集与 Command 构建
│           ├── net/                 # 网络层（连接/收发/编解码/可靠层）
│           ├── sync/                # 同步层（事件追帧/快照切换/权威帧整理）
│           ├── sim/                 # 展示用模拟态（SimulatedState：只读展示模型）
│           ├── render/              # 表现态与渲染辅助（RenderState：视觉预测/平滑）
│           ├── ui/                  # UI 独立系统（面板/控件/视图模型）
│           │   ├── model/           # UI ViewModel（UI 数据入口/订阅）
│           │   ├── panel/           # UI 面板（经济/舰队/科技等）
│           │   └── widget/          # 可复用控件（按钮/列表/通用窗口等）
│           └── debug/               # 调试工具（日志/诊断/调试 UI）
│
├── server/                          # 服务端模块（权威模拟/网络/存储）
│   ├── build.gradle                 # server 模块构建脚本
│   └── src/main/java/staraxis/server/ # server 源码根目录（目前为空，待填充服务端实现）
│
├── lwjgl3/                           # 桌面端启动壳（仅平台相关）
│   ├── build.gradle                 # 桌面端打包/运行配置（workingDir 指向 assets）
│   └── src/main/java/staraxis/lwjgl3/ # 桌面端启动代码包
│       ├── Lwjgl3Launcher.java      # 桌面启动器（创建 Lwjgl3Application(new ClientGame(), ...)）
│       ├── UiPreviewLauncher.java   # UI 预览启动器（创建 Lwjgl3Application(new UiPreviewApp(), ...)）
│       └── StartupHelper.java       # 启动辅助（macOS -XstartOnFirstThread 等）
│
├── .specify/                        # 开发规范（IDE/流程/模板等）
│
├── build.gradle                     # 根项目构建配置
├── gradle.properties                # Gradle 属性（版本号等）
└── settings.gradle                  # Gradle 模块配置（include：core/client/server/shared/lwjgl3）
```

## 关键入口文件

- **桌面端启动入口**：`lwjgl3/src/main/java/staraxis/lwjgl3/Lwjgl3Launcher.java`
- **UI 预览启动入口**：`lwjgl3/src/main/java/staraxis/lwjgl3/UiPreviewLauncher.java`
- **客户端游戏主类**：`client/src/main/java/staraxis/ClientGame.java`

---

## 模块依赖关系（最终）

- `shared`：不依赖任何模块
- `core`：可依赖 `shared`
- `client`：依赖 `core` + `shared`
- `server`：依赖 `core` + `shared`
- `lwjgl3`：依赖 `client`
