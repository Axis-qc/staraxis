# StarAxis 项目目录结构

> 目标：反映**当前仓库里实际存在的目录与文件**（含已生成的 `build/` 产物目录）。
> 
> 说明：为避免文档失真，本文件按“当前磁盘上存在什么就写什么”的原则维护。

```text
# StarAxis 游戏开发目录结构

staraxis/
├── assets/                          # 游戏资源
│   ├── fonts/                      # 字体文件
│   │   ├── AlibabaPuHuiTi-3-65-Medium.ttf  # 阿里巴巴普惠体
│   │   └── NotoSansSC-Regular.ttf  # 思源黑体
│   ├── world/                      # 世界/背景资源
│   │   ├── world_bg.png            # 世界背景图
│   │   └── world_bg_1.png          # 世界背景图（备用）
│   ├── assets.txt                  # 资源清单（自动生成）
│   └── libgdx.png                  # 默认占位图
│
├── core/                           # 核心游戏逻辑
│   └── src/main/java/io/staraxis/
│       └── Main.java               # 游戏主入口
│
├── lwjgl3/                         # 桌面端实现
│   ├── src/main/java/io/staraxis/lwjgl3/
│   │   ├── Lwjgl3Launcher.java     # 桌面启动器
│   │   └── StartupHelper.java      # 启动辅助类
│   ├── icons/                      # 应用图标
│   │   ├── logo.icns               # macOS图标
│   │   ├── logo.ico                # Windows图标
│   │   └── logo.png                # 默认图标
│   └── nativeimage.gradle          # 原生镜像配置
│
├── .specify/                       # 开发规范
│   ├── memory/constitution.md      # 项目宪章
│   └── templates/                  # 开发模板
│       ├── plan-template.md        # 开发计划模板
│       ├── spec-template.md        # 功能规范模板
│       └── tasks-template.md       # 任务模板
│
├── build.gradle                    # 项目构建配置
├── gradle.properties               # Gradle属性
├── settings.gradle                 # 模块配置
├── 游戏大纲.md                     # 游戏设计文档
└── 术语对齐.md                     # 项目术语表
```

## 关键入口文件（当前实际存在）

- 桌面端启动入口：`lwjgl3/src/main/java/io/staraxis/lwjgl3/Lwjgl3Launcher.java`
- Core 示例入口：`core/src/main/java/io/staraxis/Main.java`

## 备注

- `client/`、`server/`、`shared/` 当前仅存在（主要是 `build/` 产物目录），是否纳入构建由 `settings.gradle` 决定。
- 若你不希望把 `build/` 产物写进目录结构（避免频繁变化），我可以提供一份“仅源码 + 配置”的稳定版目录。
