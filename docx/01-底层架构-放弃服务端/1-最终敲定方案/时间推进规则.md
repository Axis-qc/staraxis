# 时间推进规则（V1）

> 版本：2026-01-12
>
> 本文档规定 **StarAxis** 的**全球时间尺度**与**可变时间倍率**机制。
>
> - **核心口径**：
>   - 现实 **24 秒** = 游戏内 **1 天**（24 h）。
>   - 默认 `timeScale = 3600`（= 86 400 秒 ÷ 24 秒）。
> - 支持“时间静止/加速”类技能，通过**局部时间倍率(Local Time Dilation)** 改写所处实体/区域的 `effectiveTimeScale`，但**技能持有者自身保持 `1.0` 交互速度**，不会被静止影响。

---

## 1. 关键量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `realDeltaS` | – | 相邻两 Tick 的真实秒数（服务器 wall-clock） |
| `globalTimeScale` | `3600` | 全局时间倍率；维护“24 s = 1 day”关系 |
| `localTimeScale(entity)` | `1.0` | 实体所处局部倍率（时间静止技能可设置 <1） |
| `effectiveTimeScale(entity)` | 公式 | `globalTimeScale × localTimeScale(entity)` |

> **例**：当某区域施加 `localTimeScale = 0.01`（极慢）时，
> - 区域内普通单位：`effective = 3600 × 0.01 = 36` ⇒ 1 real s = 36 game s
> - 技能携带者：强制 `localTimeScale = 1.0` ⇒ `effective = 3600`（不受影响）

---

## 2. Tick 推进公式

```text
Δt_game(entity) = realDeltaS × effectiveTimeScale(entity)
```

服务器每 **100 ms** Tick：

1. 取本 Tick 的 `realDeltaS`（≈0.1）。
2. 对于每系统/实体，计算其 `Δt_game`。
3. 在各系统内用 **游戏秒** 执行逻辑。

---

## 3. 时间倍率技能分类

### 3.1 减速（时间静止 / 领域减速）

| 项 | 说明 |
|----|------|
| 生效范围 | 全局（`globalTimeScale` 乘以 `slowFactor < 1`） |
| 携带者豁免 | 技能携带者强制 `localTimeScale = 1.0 / slowFactor`，因此其 `effectiveTimeScale` 恢复为 **基准 3600**（即 1.0 权威速度） |
| 其他单位 | `effective = global×1` → 时间被放慢 |
| 示例 | 终极科技：时空引擎模块，当舰船搭载时空引擎，可以改变自身时间流速（实际展示为世界变慢，而自身不受影响，1级时空引擎可以降低世界时间流速到70%（游戏推进1时需要1.42秒），持续15秒现实时间，二级降低到50%（游戏推进1时需要2秒），持续20秒现实时间，三级降低30%（游戏推进1时需要3.3秒），持续25秒现实时间，四级降低到10%（游戏推进1时需要10秒），持续30秒现实时间） |

### 3.2 加速（自身爆发加速）

| 项 | 说明 |
|----|------|
| 生效范围 | **仅自身**；不修改 `globalTimeScale` |
| 机制 | 在战斗/移动系统内部乘以 `actionSpeedBoost > 1`，影响射速、移动率等；不改变逻辑时间步 |
| 影响 | 不影响他人，也不改变 Tick 对账；可与减速叠加 |
| 示例 | 机甲超频、武器过载 |

### 3.3 实现统一流程

1. 执行减速技能 → `globalTimeScale = 3600 × slowFactor`。
2. 服务器广播 `SlowStartEvent {factor}`。
3. 技能持有者客户端收到后，设 `localTimeScale = 1/slowFactor` 保持正常。
4. 加速技能只写入 `actionSpeedBoost` 字段，系统消费。

## 4. 客户端表现

- 客户端使用同一 `effectiveTimeScale` 渲染动画播放速率、粒子帧率。  
- 若本地预测模式下 `localTimeScale` 改变，立即调整动画速率，等待权威确认后回收。

---

## 5. 监控与日志

- 每 Tick 记录 `globalTimeScale`。
- 若 `localTimeScale ≠ 1`，输出 `TimeDilationEvent {entityId, scale, duration}`。

---

## 6. 验收标准

1. **24 秒实时**完整跑一昼夜后，游戏内日历+1 天误差 ≤0.1 s。  
2. 施加时间静止后，区域外单位逻辑与动画减速，持有者保持正常速率。  
3. 重放回放文件，时间倍率变化与效果一致。
