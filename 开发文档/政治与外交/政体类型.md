# 政体类型

> 目标：定义不同政体的核心机制、加成与玩法差异，为政治系统提供基础框架。

## 1. 通用文明政体

### 1.1 独裁/帝制 (Dictatorship/Imperial)

- **核心机制**：权力集中于单一领袖，没有内部派系斗争。
- **领袖**：领袖终身制，其技能和特质对整个帝国产生强大而直接的影响。领袖的死亡可能引发继承危机。
- **玩法特点**：
  - **高控制力**：玩家可以完全自主地决定国家政策和发展方向。
  - **效率依赖领袖**：帝国的整体效率与领袖的能力强相关。
  - **稳定性风险**：稳定性较低，容易受到领袖更替或外部事件的影响。

### 1.2 民主/寡头 (Democracy/Oligarchy)

- **核心机制**：权力由选举产生的领袖或少数精英群体掌握，帝国由多个内部**派系 (Factions)** 组成。
- **派系**：每个派系都有自己的诉求和满意度。玩家需要平衡各派系的需求，否则会引发内乱或支持度下降。
- **玩法特点**：
  - **内政复杂**：需要管理派系关系，通过政策和法令来提升派系满意度。
  - **母星控制权**：母星（或核心星球）可能由特定派系掌控，其资源产出和发展方向会受到该派系诉求的影响。
  - **市场共享，资源独立**：各派系可能拥有独立的资源储备，但在国家层面共享同一个星际市场。

## 2. 特殊文明政体（格式塔意识）

格式塔意识文明（蜂巢思维、机械智能）在人口、经济和内政上拥有与通用文明完全不同的计算模型。

### 2.1 蜂巢思维 (Hive Mind)

- **核心机制**：整个文明是一个统一的超级生物，所有“人口”都是没有独立思想的子个体。
- **人口与维护**：
  - 使用 **子个体数量** 作为计量单位。
  - 依赖 **生物质 (Biomass)** 资源来维护子个体的生存和进行繁育。
  - 生物质短缺会导致子个体数量下降，引发整个巢群的崩溃。
- **财政口径**：
  - 将“税收”替换为 **巢群供给/贡赋**，体现了资源的集中调配。
- **玩法特点**：
  - **无派系**：没有内部政治和派系满意度的烦恼。
  - **快速扩张**：通常拥有较快的人口（子个体）增长速度。
  - **资源单一化风险**：对生物质的强依赖是其主要弱点。

### 2.2 机械格式塔 (Machine Intelligence)

- **核心机制**：整个文明是一个由中央AI控制的机器人网络。
- **人口与维护**：
  - 使用 **单元数量** 作为计量单位。
  - 依赖 **能源 (Energy)** 进行维护，高昂的能耗是其主要限制。
  - **算力 (Computing Power)** 是一个核心概念，限制了可控制的单元数量和整体生产效率。
- **财政口径**：
  - 将“税收”替换为 **产能分配/能耗预算**，体现了对能源和生产力的集中管理。
- **玩法特点**：
  - **无派系**：没有内部政治。
  - **高生产力**：通常在工业和矿业上有显著优势。
  - **能源依赖**：对能源的巨大需求是其扩张和维持的关键挑战。
