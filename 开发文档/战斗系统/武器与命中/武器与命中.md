# 武器与命中

> 目标：在 **2D平面** 模块化自由拼装的框架下，定义武器模块的安装、射界、命中率和伤害计算口径。

## 1. 武器模块 (Weapon Modules)

- **定义**：提供火力的功能模块，如炮塔、固定炮、导弹发射器等。
- **安装**：武器模块必须安装在舰船的**连接点**上。
- **核心属性**：
  - `baseAccuracy`: 基础命中率
  - `baseDamage`: 基础伤害
  - `optimalRange`: 最佳射程
  - `maxRange`: 最大射程
  - `firingArc`: **射界** (见下文)

### 1.1 射界 (Firing Arc)

- **概念**：武器模块能够开火的角度范围，由其在舰船上的**2D平面安装位置和朝向**决定。
- **示例**：一个安装在舰首的固定炮，其射界可能只有前向±10°；而一个炮塔则可能有270°甚至360°的射界。
- **约束**：只有当目标进入至少一个武器模块的射界和最大射程内时，该模块才能开火。

## 2. 命中率计算 (Hit Chance Calculation)

### 2.1 通用命中公式

`命中率 = 基础命中率 × (攻击方索敌 / 防御方闪避) × 射程衰减系数`

- **`基础命中率 (Base Accuracy)`**：武器模块自带的属性。
- **`攻击方索敌 (Attacker's Tracking)`**：由舰船上所有**火控计算机**、**传感器**等模块的属性**累加**，并受技能影响。
- **`防御方闪避 (Defender's Evasion)`**：由防御方舰船的**涌现属性**（总质量、总推力、2D重心、姿态调整推进器2D布局）和技能共同决定。
- **`射程衰减系数`**：见第 4 节。

**约束**：
- 计算出的最终命中率必须被限制在一个范围内，例如 `[5%, 100%]`。

### 2.2 导弹命中机制

导弹的命中分为两个阶段：

1.  **拦截阶段**：防御方的**点防模块 (Point-Defense Modules)** 会尝试击落来袭导弹。
2.  **命中阶段**：如果未被拦截，导弹将自动命中目标。导弹不计算闪避。

## 3. 伤害计算 (Damage Calculation)

### 3.1 基础伤害公式

`单次命中伤害 = (基础伤害 × (1 + 伤害加成百分比))`

- **`基础伤害 (Base Damage)`**：武器模块自带的属性。
- **`伤害加成百分比`**：来自科技、领袖技能、舰船上其他模块（如伤害增幅器）等的加成总和。

> **注**：此伤害为**初始伤害**。它如何作用于具体的模块、以及如何被护盾和装甲减免，详见 **《防御与伤害结算.md》**。

---

## 4. 射程与衰减 (Range and Falloff)

### 4.1 核心射程属性

每个武器模块都具备以下射程属性：

- **`最佳射程 (Optimal Range)`**
- **`最大射程 (Max Range)`**

### 4.2 射程衰减规则（口径）

- **衰减目标**：射程衰减主要影响**命中率**。
- **衰减区间**：当 `当前距离` > `最佳射程` 时，开始衰减。
- **衰减公式（线性衰减示例）**：

  `射程衰减系数 = 1.0 - ( (当前距离 - 最佳射程) / (最大射程 - 最佳射程) ) * 衰减惩罚`

  - **`衰减惩罚 (Falloff Penalty)`**：一个数据驱动的参数（例如 0.5）。
