# 信息架构摘要字段

> 目标：定义各视角层级在“非深入模式”下应该展示的摘要字段集合，避免 UI 信息密度与口径分裂。

## 1. 星区/星域视角（Sector/Region View）摘要字段

- 星区类型（恒星系/深空/星云/风暴/资源区）
- 关键 POI 数量（恒星系数量、遗迹点等）
- 我方/敌方舰队数量摘要
- 补给线状态（正常/紧张/断裂）

## 2. 恒星系视角（Star System View）摘要字段

- 恒星类型
- 行星数量与殖民状态摘要
- 轨道设施摘要（船坞等级、防御平台数量）
- 友方/敌方舰队战斗态势摘要

## 3. 行星地表视角（Planet Surface View）摘要字段

- 人口（UI 显示单位）
- 岗位与住房摘要
- 电力网络状态
- 行星护盾状态
