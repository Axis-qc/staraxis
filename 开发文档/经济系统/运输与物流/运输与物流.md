# 运输与物流

> 目标：定义资源在星际之间流动的口径、运输舰的多功能职责，以及运输任务的优先级规则。

## 1. 运输舰（Transport Ship）

运输舰是帝国非战斗核心单位，合并了传统的物流、殖民和建设功能。

- **核心职责**：
  1.  **经济物流**：执行由行星市场生成的常规进出口订单。
  2.  **军事后勤**：为舰队提供补给。
  3.  **人口转移**：将人口从一个已殖民星球运送到一个新的殖民地，是帝国扩张的关键。
  4.  **太空建设**：为太空设施（如空间站、船坞、交通设施）的建造运输所需资源。

- **核心属性（口径）**：
  - `capacity`: 运载容量（可同时运输资源和人口）。
  - `speed`: 航行速度。

- **获取方式**：由**民用港**根据“运输舰数量上限”自动建造。

## 2. 物流流转（概念口径）

- 产出发生在“节点”（行星/太空设施）。
- 库存存储在“节点”。
- 运输舰在节点之间搬运库存，完成物流流转。

## 3. 运输任务优先级（口径）

当多个运输任务需要分配运输舰时，必须遵循明确的优先级规则。以下为推荐的优先级分级，具体数值和条件可在数据中配置。

| 优先级 | 任务类型 | 描述 | 示例 |
|---|---|---|---|
| **5 (最高)** | **紧急军事补给** | 为正在战斗或即将进入战斗的舰队补充弹药/食物。 | 舰队补给条低于20%。 |
| **4 (高)** | **必需品进口 / 人口转移** | 为出现赤字的行星进口生存必需品，或将人口运送到新殖民地以启动发展。 | 行星食物库存为0；运输首批100单位人口到新殖民的星球。 |
| **3 (中)** | **常规军事补给** | 为非紧急状态的舰队进行常规补给，使其保持满员状态。 | 舰队在己方星域内休整。 |
| **2 (低)** | **常规经济运输** | 执行由行星市场生成的常规出口和进口订单。 | 出口盈余的矿物，进口发展所需的合金。 |
| **1 (最低)** | **太空/地面建设** | 为非紧急的太空设施或地面奇观运输物资。 | 运输资源用于建造一个环形加速器或环世界。 |

> 注：运输系统在分配运输舰时，应优先服务高优先级的任务。同一优先级内的任务可按“先到先得”或“距离最近”等策略进一步排序。
