# 经济系统口径（结算口径）

> 目标：统一资源结算、两级财政体系与“按日结算”的可复算规则口径。

> 本文档聚焦“结算”；资源分级、市场、运输的细节请分别参考：
> - `经济系统/资源与产业链/资源与产业链.md`
> - `经济系统/市场与贸易/市场与贸易.md`
> - `经济系统/运输与物流/运输与物流.md`

## 1. 结算的层级与对象

- **资源结算**：在每个节点（行星、空间站）上进行的**实物资源**（矿物、食物、能源等）的产出与消耗结算。
- **财政结算**：在**星球首都**和**国家**层面进行的**货币/信用点**的收入、支出与上缴结算。

## 2. 资源结算（按日）

### 2.1 结算流水线

推荐统一口径（可在后续版本细化，但不得各系统各自为政）：

1.  期初库存
2.  + 当日产出
3.  - 当日维护消耗
4.  - 当日人口/建筑消耗
5.  + 当日进口
6.  - 当日出口
7.  得到期末库存

### 2.2 输入项（示例）

- `stockpileStart`：期初库存
- `production`：当日产出
- `consumption`：当日消耗
- `maintenance`：当日维护消耗
- `imports` / `exports`：当日进出口

> **注**：“当日生产”的核心来源是行星上的**城市**及其内部的岗位，以及轨道设施。详见《资源与产业链.md》。

## 3. 财政结算（按日，在资源结算之后）

### 3.1 两级财政体系

- **星球财政账户 (Planetary Account)**：
  - **持有者**：每个星球的**首都**。
  - **功能**：管理本星球的财政收支。所有本地收入首先进入此账户。
- **国家财政账户 (National Account)**：
  - **持有者**：整个帝国。
  - **功能**：管理中央财政，用于国家级的开支（如大型舰队维护、国家奇观建设、星际市场干预等）。

### 3.2 财政结算流水线

1.  **计算星球本地收入**：
    -   `税收 (Tax)`：根据人口和税率政策计算。
    -   `贸易盈余 (Trade Surplus)`：通过星际市场交易产生的利润。
2.  **更新星球财政账户**：
    -   `星球账户余额 += 税收 + 贸易盈余`
3.  **计算上缴金额**：
    -   `上缴金额 (Upkeep) = 星球本地总收入 * 上缴比例`
    -   `上缴比例` 是一个由国家政策决定的数据驱动值。
4.  **执行上缴**：
    -   `星球账户余额 -= 上缴金额`
    -   `国家账户余额 += 上缴金额`
