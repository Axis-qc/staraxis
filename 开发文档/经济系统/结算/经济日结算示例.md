# 经济日结算示例

> 目的：验证“按日结算”的计算流程可复现，并作为实现参考。本示例分为“资源结算”和“财政结算”两部分。

---

## Part 1: 资源结算

### 输入 (资源)
```yaml
# 期初库存
stockpileStart:
  minerals: 1000
  food: 500
  energy: 2000

# 当日产出
production:
  minerals: 500
  food: 300
  energy: 1000

# 维护消耗
maintenance:
  energy: 800

# 人口/建筑消耗
consumption:
  food: 400
  energy: 200

# 贸易（净额）
imports:
  minerals: 100

exports:
  energy: 300
```

### 计算过程 (资源结算)

1.  **期初库存**: `minerals: 1000`, `food: 500`, `energy: 2000`
2.  **+ 产出**: `minerals: 1500`, `food: 800`, `energy: 3000`
3.  **- 维护**: `energy: 2200`
4.  **- 消耗**: `food: 400`, `energy: 2000`
5.  **+ 进口**: `minerals: 1600`
6.  **- 出口**: `energy: 1700`

### 期末库存 (资源结果)
```yaml
minerals: 1600
food: 400
energy: 1700
```

---

## Part 2: 财政结算 (在资源结算之后)

### 输入 (财政)
```yaml
# 财政期初余额
planetaryAccountStart: 10000  # 星球账户
nationalAccountStart: 500000 # 国家账户

# 当日财政收入
taxRevenue: 1500          # 来自人口和政策
tradeSurplus: 500           # 来自星际贸易的利润

# 国家政策
upkeepPercentage: 0.5       # 上缴比例 50%
```

### 计算过程 (财政结算)

1.  **计算星球本地总收入**
    -   `本地总收入 = 税收 + 贸易盈余 = 1500 + 500 = 2000`

2.  **更新星球财政账户 (收入)**
    -   `星球账户余额 = 期初余额 + 本地总收入 = 10000 + 2000 = 12000`

3.  **计算上缴金额**
    -   `上缴金额 = 本地总收入 * 上缴比例 = 2000 * 0.5 = 1000`

4.  **执行上缴**
    -   `星球账户余额 -= 上缴金额`  (12000 - 1000 = 11000)
    -   `国家账户余额 += 上缴金额`  (500000 + 1000 = 501000)

### 期末财政余额 (结果)
```yaml
planetaryAccountEnd: 11000
nationalAccountEnd: 501000
```
