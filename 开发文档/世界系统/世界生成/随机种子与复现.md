# 随机种子与复现

> 目标：确保同一世界生成配置在相同随机种子下可复现，便于调试、回放与多人一致性。

## 1. 复现原则

- 相同：开局配置 + 随机种子 + 生成版本号 → 必须生成相同世界
- 生成器必须是确定性的：禁止依赖非确定性来源（系统时间、线程调度顺序等）

## 2. 随机源使用口径

- 世界生成必须使用“统一随机源”或“可追溯的子随机源”（按星区ID/阶段派生）
- 每一步生成记录：阶段名、输入参数摘要、输出摘要（用于定位差异）

## 3. 版本号（口径）

- 建议定义 `worldGenVersion`（用于兼容未来生成逻辑变更带来的复现差异）
- 同一版本号下必须严格复现
