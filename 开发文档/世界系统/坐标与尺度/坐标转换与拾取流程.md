# 坐标转换与拾取流程（屏幕 → Local/World → 命中 → 指令）

> 目标：统一客户端从“屏幕坐标/鼠标输入”到“命中对象/命中点”的坐标转换流程，并明确发往服务端的指令（Command）应携带哪些坐标与标识。

## 0. 核心约束（必须遵守）

- **渲染与拾取必须用 Local**：任何点击/框选/射线检测/距离判定等交互查询，一律在 **Local 坐标系**中完成。
- **网络与存档必须用 World**：任何发送给服务端/写入存档的位置数据，一律使用 **World 坐标系**表达。
- **Rebase 不改变世界**：Rebase 仅改变客户端的本地原点（Local ↔ World 转换基准），不得改变权威世界状态。

## 1. 输入与前置数据

### 1.1 客户端输入

- `screenPosPx`：屏幕像素坐标（鼠标/触屏位置）
- `inputAction`：输入动作（点击/拖拽/框选/右键指令等）

### 1.2 必须已知的相机/坐标参数

- `cameraWorldCenter`：相机中心的世界坐标（World）
- `sectorCenterWorldPos`：当前本地原点（星区中心）的世界坐标（World）
- `zoomFactor`：缩放因子
- `cameraTransform`：屏幕 ↔ 相机平面 的变换参数（实现细节）

> 注：具体变换矩阵属于实现细节，本文件只定义“输入/输出的坐标域”。

## 2. 屏幕坐标 → Local 坐标（拾取坐标）

### 2.1 计算 `localPickPos`

目标：把 `screenPosPx` 映射到当前可交互平面上的 **Local 坐标**。

- 输出：`localPickPos`（Local）
- 使用：该坐标只用于客户端拾取、命中判定与视觉反馈。

### 2.2 命中检测（Local）

在 Local 中进行命中检测：

- **对象命中**：根据对象在 Local 中的包围盒/半径/形状判定命中。
- **区域命中**：例如星区六边形、恒星系范围圈等。

输出：
- `hitType`：命中类型（对象/地面/空）
- `hitObjectId`：命中对象 ID（若命中对象）
- `hitLocalPos`：命中点 Local 坐标（用于显示命中标记）

## 3. Local 命中点 → World 命中点

服务端需要使用 World 坐标进行规则计算与校验，因此客户端必须把命中点转换为 World。

- 输入：`hitLocalPos`（Local）
- 输出：`hitWorldPos = hitLocalPos + sectorCenterWorldPos`（World）

## 4. 生成指令（Command）并发送给服务端（选择 B）

你已选择 **B：发送 `objectId + worldPos`**。

### 4.1 指令内容口径

- **对象交互类指令**（例如选中舰队并下达移动）：
  - 必须包含：
    - `targetObjectId`（被命中的对象，如 planetId/cityId/fleetId）
    - `hitWorldPos`（用于服务端校验/容错/重算）

- **点地类指令**（例如移动到某位置）：
  - 必须包含：
    - `destinationWorldPos`
  - 可选包含：
    - `destinationSectorId`（减少服务端查找成本）

### 4.2 服务端校验口径（建议）

服务端收到 `objectId + worldPos` 后：

1. 以 `objectId` 查找权威对象
2. 以对象权威位置与 `hitWorldPos` 做一致性校验（容差）
3. 若偏差过大：拒绝指令并返回原因（避免作弊/反序列化错误/客户端不同步）

## 5. 常见流程示例（从用户动作到指令）

### 5.1 点击行星进入地表

1. 客户端：`screenPosPx` → `localPickPos`
2. 客户端：命中 `planetId`，得到 `hitLocalPos`
3. 客户端：`hitLocalPos` → `hitWorldPos`
4. 客户端：发送 `EnterPlanetSurfaceCommand(planetId, hitWorldPos)`

### 5.2 右键下达舰队移动

1. 客户端：`screenPosPx` → `localPickPos`
2. 客户端：命中“空地/目标点”，得到 `hitLocalPos`
3. 客户端：`hitLocalPos` → `destinationWorldPos`
4. 客户端：发送 `MoveFleetCommand(fleetId, destinationWorldPos)`

## 6. Rebase 相关注意事项（实现自检）

- Rebase 发生的那一帧：
  - 先确定使用哪个 `sectorCenterWorldPos` 作为本帧基准
  - 再进行渲染与拾取
  - 不允许渲染用旧原点、拾取用新原点（或反之）
