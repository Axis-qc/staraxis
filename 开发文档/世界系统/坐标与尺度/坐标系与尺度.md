# 坐标系与尺度

> 目标：在大尺度宇宙地图下避免浮点抖动，并统一坐标/角度/缩放换算口径。

## 1. 轴向与角度（2D）

- X 轴：向右为正（+X）
- Y 轴：向上为正（+Y）
- 角度：0° 向右，90° 向上，180°/ -180° 向左，-90° 向下

## 2. 双坐标系（防抖）

### 2.1 世界坐标系（World）

- 用途：跨星区/星域的全局定位（大地图层）
- 原点：世界中心 (0,0)

### 2.2 本地坐标系（Local）

- 用途：恒星系内部、战斗、交互查询等高精度场景
- 原点：默认以“当前星区六边形中心”作为本地原点

## 3. World ↔ Local 转换规则

设：
- `worldPos`：世界坐标
- `sectorCenterWorldPos`：星区中心的世界坐标

则：
- `localPos = worldPos - sectorCenterWorldPos`
- `worldPos = localPos + sectorCenterWorldPos`

## 4. 使用域规定（必须遵守）

- 渲染与交互拾取：优先使用 **Local**（避免抖动）
- 星区/星域导航与持久化定位：使用 **World**

## 5. Rebase（坐标重定位）触发条件

当“相机中心点”距离当前 `sectorCenterWorldPos` 超过阈值时，允许切换本地原点到新的星区中心：

- 触发：`distance(worldCameraCenter, sectorCenterWorldPos) > rebaseThreshold`
- 行为：更新 `sectorCenterWorldPos`，并保持屏幕上对象位置连续

> 注：阈值以“不会影响交互精度”为准；具体数值在实现阶段确定。

## 6. 比例尺与缩放换算

### 6.1 标准比例尺

- 标准 `zoomFactor = 1` 时：**100px = 1 AU**
- 因此：`1px = 0.01 AU`

### 6.2 通用换算

- `distancePerPixelAU = 0.01 * zoomFactor`
- `distanceAU = d_px * distancePerPixelAU`

## 7. 误差预算（验收口径）

- 在恒星系/战斗视角下：同一静止目标在镜头缓慢平移时，屏幕位置不应出现肉眼可见抖动。
- 在跨星区移动并触发 rebase 时：对象在屏幕上的位置变化应连续，无“跳帧式瞬移”。
