## 1. 核心原则与约定

- **坐标手性**：本文档不强绑定引擎坐标手性。
  - 若项目采用 3D：推荐统一为引擎惯用手性（Unity 左手/Unreal 左手），并在渲染层做一次性适配。
  - 本文档所有公式仅依赖轴向定义，不依赖手性。
- **轴向（逻辑空间）**：X 轴向右，Y 轴向上，Z 轴为深度/高度轴（项目可将 Z=0 作为星图平面）。
- **角度（2D）**：
  - 0°：沿 +X 轴。
  - 90°：沿 +Y 轴。
  - 180° / -180°：沿 -X 轴。
  - -90°：沿 -Y 轴。
- **数据类型与使用域**：
  - **权威坐标**：`double`（float64），单位为 **GU**。用于服务端模拟、存档、网络、宏观导航。
  - **表现坐标**：`float`（float32）。仅用于客户端渲染与物理（相机附近相对坐标）。

## 2. 坐标系统（权威 + 星区本地 + 镜头渲染）

> 本项目采用：
> - **权威坐标单位**：GU（缩小宇宙 1:100,000）
> - **星区坐标**：hex axial `(q,r)`
> - **星区本地坐标**：相对星区锚点/恒星系锚点的小范围坐标
> - **镜头坐标系**：仅用于客户端渲染（不进入存档/网络权威）

### 2.1 权威位置结构 `GlobalPosition`

> 口径：任何实体都应有一个权威位置 `GlobalPosition`。网络同步与存档只传/存 `GlobalPosition`（或其序列化形式），禁止传/存 float 渲染坐标。

```csharp
public struct SectorCoord
{
    public int Q; // axial q
    public int R; // axial r
}

public struct GlobalPosition
{
    public SectorCoord Sector;      // 层级 1: 星区坐标（hex axial）
    public Vector3d SystemPosAU;    // 层级 2: 星区内偏移（AU，用于宏观布局/生成）
    public long SystemId;           // 归属恒星系ID（用于定义 LocalPosGU 的原点）
    public Vector3d LocalPosGU;     // 层级 3: 恒星系/星区本地偏移（GU，相对 system 主星/锚点）
}
```

> 注：`SystemPosAU` 用于“星区内系统布局”，`LocalPosGU` 用于“系统内/战斗内/精细模拟”。

### 2.2 各层级用途与范围

- **层级 1：星区（Sector/Hex）**
  - 用途：大地图定位、分片、星区寻路（A*）。
  - 坐标：axial `(q,r)`。

- **层级 2：星区内（SystemPosAU）**
  - 用途：星区内恒星系布局、星区内航行（粗）。
  - 单位：AU。

- **层级 3：恒星系/星区本地（LocalPosGU）**
  - 用途：恒星系内所有天体/舰队/战斗等精细模拟。
  - 单位：GU。

- **层级 4：镜头渲染坐标（Camera / Render Space）**
  - 用途：客户端渲染/物理。
  - 坐标：`Vector3f`（float32）。
  - 原点：相机所在的权威世界坐标（GU）。

## 3. 常量与单位（必须统一）

- **最重要：1:100,000 缩小的宇宙（权威坐标单位）**
  - 游戏内采用 **1:100,000** 的现实尺度缩放。
  - 定义 **权威坐标单位**：`1 坐标单位（Game Unit, GU） = 100,000 米（m）`。
  - 游戏的“世界坐标/数据坐标”应直接使用 `GU` 作为单位。

- `GAME_UNIT_IN_METERS = 100_000`
- `AU_IN_METERS = 149_597_870_700`
- `LY_IN_METERS = 9_460_730_472_580_800`

- 六边形布局：**pointy-top（尖顶）**（本文件后续所有 hex 公式基于该约定）

- **权威 1.0 缩放（渲染基准）**：将 `zoom=1.0` 作为全局渲染换算的**权威基准**。
  - 在 `zoom=1.0` 下：屏幕 **1 像素（px）** 严格对应 **1 坐标单位（GU）**。
  - `1px = 1GU = 100,000m`（at `zoom=1.0`）
  - **缩放语义**：`zoom` 仅表示“视野缩放/画面缩放”。
    - `guPerPixel(z) = z`
    - `screenDeltaPx = worldDeltaGU / guPerPixel(z)`

- **举例（用于校验数据/渲染一致性）**
  - **距离换算**：地球与太阳真实距离约 `149,597,870,700m`。
    - 换算为游戏内：`149,597,870,700 / 100,000 = 1,495,978.707 GU`。
    - 若以太阳为原点 `(0,0)`，并把行星沿 `+X` 轴排列，则地球位置应约为：`(x=1,495,978.707, y=0) GU`。
  - **尺寸换算**：地球真实直径 `12,742,000m`。
    - 换算为游戏内直径：`12,742,000 / 100,000 = 127.42 GU`。
    - 在 `zoom=1.0` 渲染基准下，地球直径应约为 `127.42px`；在 `zoom=2.0` 下约为 `63.71px`。

## 4. 六边形星区：距离、编码、中心点换算（单位：GU）

### 4.0 大地图拼接口径

- 大地图由多个六边形星区（hex sector）**拼接**而成。
- 任意实体的宏观定位均落在某个 `(q,r)` 星区内；跨星区的移动/导航以星区为主路径。
- 星区 `(q,r)` 的中心点由 `SectorCenterWorldPosGU()` 计算，作为该星区内所有恒星系与事件的“宏观锚点”。

### 4.1 axial ↔ cube

- `x = q`
- `z = r`
- `y = -x - z`

### 4.2 六边形距离（环数）

```csharp
public static int HexDistance(SectorCoord a, SectorCoord b)
{
    int ax = a.Q;
    int az = a.R;
    int ay = -ax - az;

    int bx = b.Q;
    int bz = b.R;
    int by = -bx - bz;

    return (Math.Abs(ax - bx) + Math.Abs(ay - by) + Math.Abs(az - bz)) / 2;
}
```

### 4.3 星区主键编码（可选）

```csharp
public static long PackSectorKey(int q, int r)
{
    return ((long)q << 32) ^ (uint)r;
}
```

### 4.4 星区中心点世界坐标（GU）

> 星区直径口径：每个六边形星区的 **直径（flat-to-flat）** 为 `10000GU`。

```csharp
public const double AU_IN_GU = AU_IN_METERS / GAME_UNIT_IN_METERS;
public const double LY_IN_GU = LY_IN_METERS / GAME_UNIT_IN_METERS;

public const double SECTOR_DIAMETER_LY = 1;
public const double SECTOR_DIAMETER_GU = SECTOR_DIAMETER_LY * LY_IN_GU;

// pointy-top hex：flat-to-flat diameter = 2*size
public const double SECTOR_SIZE_GU = SECTOR_DIAMETER_GU / 2.0;

public static Vector2d SectorCenterWorld2D_GU(SectorCoord s)
{
    double size = SECTOR_SIZE_GU;
    double x = size * (Math.Sqrt(3) * s.Q + Math.Sqrt(3) / 2.0 * s.R);
    double y = size * (3.0 / 2.0 * s.R);
    return new Vector2d(x, y);
}

public static Vector3d SectorCenterWorldPosGU(SectorCoord s)
{
    var p = SectorCenterWorld2D_GU(s);
    return new Vector3d(p.X, p.Y, 0);
}
```

## 5. WorldPosGU 组合/拆分（权威绝对坐标，单位：GU）

> 口径：所有需要绝对距离的计算，基于 `WorldPosGU`（GU）。

### 5.1 组合（推荐）

如果约定“恒星系主星位于星区内偏移 `SystemPosAU` 处”，则可直接：

```csharp
public static Vector3d WorldPosGU(GlobalPosition gp)
{
    Vector3d sectorCenter = SectorCenterWorldPosGU(gp.Sector);

    // SystemPosAU 是 AU 单位，转换为 GU
    Vector3d systemOffsetGU = gp.SystemPosAU * AU_IN_GU;

    // LocalPosGU 为 GU
    return sectorCenter + systemOffsetGU + gp.LocalPosGU;
}
```

## 6. 镜头坐标系（客户端渲染/物理）

> 镜头坐标系是**客户端渲染系统**：不进入网络/存档权威，仅用于把大世界的权威坐标转换为相机附近的稳定数值（通常 float32）。

### 6.1 渲染相对坐标（GU -> RenderSpace）

```csharp
// cameraWorldPosGU：相机的权威世界坐标（GU）
// zoom：渲染缩放，zoom=1 时 1px=1GU
public static Vector3f RenderPos(GlobalPosition obj, Vector3d cameraWorldPosGU, double zoom)
{
    Vector3d objWorldGU = WorldPosGU(obj);
    Vector3d relativeGU = objWorldGU - cameraWorldPosGU;

    // 最终进入渲染/屏幕的单位：px
    // screenDeltaPx = relativeGU / zoom
    return (Vector3f)(relativeGU / zoom);
}
```

## 7. GlobalPosition 的序列化规范（网络/存档）

### 7.1 原则

- 网络/存档仅传/存 `GlobalPosition`。
- 客户端渲染层的镜头坐标（float32）禁止传/存。

### 7.2 建议编码（V1）

- `Sector.q`：int32
- `Sector.r`：int32
- `SystemPosAU`：float32（量化）
- `SystemId`：int64
- `LocalPosGU`：float32（或更高精度的定点量化，视战斗需求）

## 8. 与拾取流程接口（对齐《坐标转换与拾取流程.md》）

- 屏幕点击 → 得到屏幕/渲染空间坐标（px）。
- 转回权威世界坐标：
  - `worldDeltaGU = screenDeltaPx * zoom`
  - `worldPosGU = cameraWorldPosGU + worldDeltaGU`
- 在 `worldPosGU` 上做：
  - `World2DToSector()` 以确定候选分片
  - 转成目标恒星系 local space 做精确命中
