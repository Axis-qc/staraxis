# 坐标转换示例

> 目的：验证 `世界坐标 ↔ 本地坐标` 与 `px ↔ AU` 的换算口径可复算。

## 示例 1：World → Local

已知：
- `sectorCenterWorldPos = (1000, 2000)`
- `worldPos = (1300, 2600)`

计算：
- `localPos = worldPos - sectorCenterWorldPos = (300, 600)`

## 示例 2：Local → World

已知：
- `sectorCenterWorldPos = (1000, 2000)`
- `localPos = (-50, 20)`

计算：
- `worldPos = localPos + sectorCenterWorldPos = (950, 2020)`

## 示例 3：像素距离 → AU

已知：
- `zoomFactor = 2`
- `d_px = 150px`

计算：
- `distancePerPixelAU = 0.01 * zoomFactor = 0.02 AU/px`
- `distanceAU = d_px * distancePerPixelAU = 150 * 0.02 = 3 AU`
