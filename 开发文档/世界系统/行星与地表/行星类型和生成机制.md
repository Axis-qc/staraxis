# 行星类型和生成机制

> 目标：定义不同类型的行星、其核心属性以及生成地表特征的规则，为世界生成提供多样性和确定性基础。

## 1. 行星类型（Planet Types）

此列表为基础分类，可在后续通过数据驱动扩展。

### 1.1 有大气层行星

| 类型（中文） | 建议英文ID | 核心特征 |
|---|---|---|
| 大陆行星 | continental | 类似地球，宜居性高，地形多样 |
| 海洋行星 | ocean | 绝大部分被液态水覆盖，陆地稀少 |
| 荒漠行星 | desert | 干燥，水资源稀缺，可能有极端温差 |
| 极地行星 | arctic | 表面被冰雪覆盖，气候寒冷 |

### 1.2 无大气层行星

| 类型（中文） | 建议英文ID | 核心特征 |
|---|---|---|
| 岩石行星 | rocky | 表面为岩石，无生命迹象，富含矿物 |
| 熔岩行星 | lava | 表面为熔岩，温度极高，无法殖民 |
| 气态巨行星 | gas-giant | 体积巨大，无实体表面，可进行轨道资源采集 |

## 2. 核心属性（Core Attributes）

每个行星在生成时都应具备以下核心属性，用于后续的模拟和玩法。

- `planetType`: 行星类型（引用上述ID）。
- `size`: 行星大小（一个抽象值，例如 10-20，影响可建立的城市上限和开发规模修正）。
- `planetSizeModifier`: **星球大小加成**。根据 `size` 计算出的修正系数，星球越大，此系数越小。
- `gravity`: 重力（影响建筑成本、发射效率等）。
- `resourceRichness`: 资源丰富度（一个或多个资源的乘数因子）。
- `habitability`: 宜居性（影响人口增长、幸福度等）。
- `surfaceFeatures`: **地表特征列表**。一个包含该行星所有大陆和海洋的列表。

## 3. 生成机制（Generation Mechanism）

- **约束**：行星的生成必须是**确定性的**，即在相同的随机种子和生成参数下，结果必须一致。
- **流程口径**：
  1. 在恒星系生成阶段，根据预设规则（如轨道位置、恒星类型等）决定要生成的行星数量和类型。
  2. 为每个行星随机分配其核心属性（`size`, `gravity` 等），并根据 `size` 计算出 `planetSizeModifier`。
  3. **生成地表特征**：执行以下子流程来构建行星的 `surfaceFeatures` 列表：
     a. 根据行星类型（如海洋行星、大陆行星）决定大陆和海洋的基础比例。
     b. 使用随机名称生成器，创建若干个“大陆”和“海洋”对象。
     c. 通过分割算法（如随机划分100%的总空间），为每个大陆和海洋分配其 `surfacePercentage`。
     d. 对每个主要特征，再按规则生成其“次级地形”（如山脉、浅海）及其百分比。
  4. 将生成的所有地表特征数据存入行星的 `surfaceFeatures` 属性中。

> 具体的玩法规则（如城市建设、可开发空间等）详见 `行星与城市设计.md`。
