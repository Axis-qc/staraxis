# 行星与城市设计

> 目标：定义以“宏观城市建设”为核心的行星地表玩法，并引入地表特征、城市专精、星球首都和两级财政等机制，增加行星的独特性和发展策略。

## 1. 核心概念

- **取消网格**：行星地表不进行微观网格管理。
- **聚焦城市**：所有地表活动围绕“城市”这一宏观单位。
- **地表特征驱动**：行星被划分为不同的大陆和海洋，这些“地表特征”是建立城市和获取资源的基础。
- **城市专精**：玩家可以为城市指定发展方向，使其专注于特定产出。
- **星球首都**：每个行星都有一个首都，作为其行政和财政中心。

## 2. 地表特征（Surface Features）

每个行星都由多个随机命名的地表特征组成，它们共同构成了行星100%的地表空间。

### 2.1 主要特征（Continents & Oceans）

- **类型**：大陆（Continent）、海洋（Ocean）。
- **属性**：
  - `name`: 随机生成的名称（例如，“希望大陆”，“宁静之海”）。
  - `surfacePercentage`: 该特征占据行星地表总面积的百分比。

### 2.2 次级地形（Sub-Features）

每个主要特征内部还可以包含次级地形，进一步影响其利用价值。

- **类型**：山脉（Mountains）、浅海（Shallow Sea）、平原（Plains）等。
- **属性**：
  - `percentageOfFeature`: 该地形占据其所属主要特征面积的百分比。

### 2.3 可开发空间（Developable Space）

- **概念**：玩家在特定地表特征上能够进行建设的总空间上限。
- **科技限制**：`可开发空间` 受限于玩家的科技水平。

## 3. 城市设计

### 3.1 建立城市

- 玩家可以在一个地表特征的“可开发空间”内建立城市。
- 在一个星球上建立的**第一个城市**自动成为该星球的**星球都市（首都）**。

### 3.2 城市成长阶段

城市会随着时间推移和发展，经历不同的成长阶段。

1.  **殖民地 (Colony)**
2.  **聚落 (Settlement)**
3.  **镇区 (Township)**
4.  **都市 (Metropolis)**
5.  **巨都 (Megalopolis)**

### 3.3 城市功能

- **提供住房与岗位**：城市规模越大，提供的 `housing` 和 `jobSlots` 越多。
- **消耗与产出**：人口填充岗位，消耗原料产出资源。产出类型和效率与城市所在的**地表特征**和**城市专精**相关。

### 3.4 城市专精（City Specialization）

- **概念**：玩家可以为城市指定一个“专精”方向，使其在特定领域获得显著的产出加成，但可能会在其他领域有轻微减益。
- **专精类型（示例）**：
  - **科研城市**：重点产出科研点数。
  - **采矿城市**：重点产出矿物资源，通常建立在富含矿物的地表特征上。
  - **工业城市**：专注于将原材料加工成工业品和合金。
  - **行政都市**：提升行星的行政效率，可能影响税收或稳定度。
  - **农业城市**：重点产出食物。

## 4. 星球首都与财政

### 4.1 星球都市（Planetary Capital）

- **指定**：每个星球有且仅有一个首都，通常是该星球上建立的第一个城市。
- **独特功能**：首都是该星球**财政账户**的管理者，并可能提供一些行星级的行政加成。

### 4.2 两级财政体系

- **星球财政账户**：每个星球的首都都持有一个独立的财政账户。该星球所有的本地收入（如税收、贸易盈余）首先结算到这个账户中。
- **国家财政账户**：整个帝国的中央财政账户。
- **上缴机制**：根据国家政策，每个星球的财政账户需要按一个固定的比例（例如，税率的50%）将收入**上缴**到国家财政账户。这一机制实现了中央集权与地方发展的平衡。

## 5. 星球开发规模

### 5.1 星球大小加成（Planet Size Modifier）

- **概念**：一个修正系数，用于体现“在不同大小的星球上，同等规模的城市所代表的开发程度不同”。
- **规则**：星球越大，其 `planetSizeModifier` 系数越小。

### 5.2 总开发规模计算

`totalDevelopmentScale = Σ (city_i.scale * planetSizeModifier)`

### 5.3 视觉表现：地表灯光

- 行星地表灯光的亮度和范围，直接与该行星的 `totalDevelopmentScale`（总开发规模）挂钩，为玩家提供直观的开发程度反馈。
