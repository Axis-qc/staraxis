# game 模块目录结构

> `game` 模块是 StarAxis 的核心，负责执行所有权威的游戏模拟与规则计算。本模块应保持纯粹，不依赖任何前端或网络层实现。

---

game/src/main/java/staraxis/game
|-- GameRuntime.java             # **游戏运行时接口**：`game` 模块对外的唯一入口，定义了 `start/update/stop` 等生命周期，供 `webnet` 等上层模块调用。
|-- SimpleGameRuntime.java       # **简化运行时实现**：用于最小化/占位的 `GameRuntime` 实现，仅维护并递增 `simulationTick`。
|-- StarAxisGameRuntime.java     # **游戏运行时核心实现**：封装了 `tick` 循环、`WorldState` 更新、以及向外发布只读快照（`RealTimeWorldState` / `DailySettlementState`）的核心逻辑。
|-- 文件结构.md                  # 本文件：目录结构索引
|
|-- command/                    # **命令系统**：在模拟 tick 内统一执行的游戏命令队列与处理器。
|   |-- Command.java            # **命令基类**：所有游戏命令的基类，定义命令类型标识。
|   |-- CommandHandler.java     # **命令处理器接口**：定义命令处理的标准契约（泛型 + handle）。
|   |-- CommandBus.java         # **命令总线**：维护命令队列、处理器注册表，在 tick 中批量执行命令。
|   |-- SetTimeScaleCommand.java # **设置时间倍率命令**：表示调整时间推进速度的意图。
|   `-- SetTimeScaleHandler.java # **时间倍率处理器**：在 tick 内设置 SimulationTime.timeScale。
|
|-- astro/                     # **天文学（Astro）**：恒星、行星、轨道等核心天文对象的定义、生成与容器。
|   |-- def/                   # **数据定义（Data Definition）**：从 JSON 资产加载的数据模型，只读。
|   |   |-- AstroAssetRepository.java # 资产仓库，负责加载所有天文相关的 JSON 定义。
|   |   |-- OrbitPresetDef.java     # 轨道生成预设（行星数量、轨道间距等）。
|   |   |-- OrbitPresetsFile.java   # **轨道预设文件模型**：用于承载一组 `OrbitPresetDef` 的文件级数据结构（含 `schemaVersion` 与 `presets`）。
|   |   |-- PlanetTypeDef.java      # 行星类型定义（如 `TERRESTRIAL`）。
|   |   `-- StarTypeDef.java        # 恒星类型定义（如 `G_MAIN_SEQUENCE`）。
|   |-- AstroData.java         # **权威天文数据容器**：在 `WorldState` 中持有所有生成的恒星系（`StarSystem`）列表。
|   |-- AstroGenerator.java    # **星体生成器**：根据 `def` 和世界种子，确定性地生成恒星与行星，仅在世界创建时调用。
|   
|   |-- PlanetBody.java        # **行星实体**：权威的行星对象，继承自 `Entity`，包含地表组件引用喵。
|   |-- StarBody.java          # **恒星实体**：权威的恒星对象，继承自 `Entity`。
|   `-- StarSystem.java        # **恒星系**：包含一个重心、多颗恒星和多颗行星的聚合根。
|
|-- entity/                    # **游戏实体（Entity）**：游戏世界中所有“可交互/可定位”对象的基类。
|   |-- Entity.java            # **实体基类**：定义了 `entityId`, `entityType`, `posWorldGU` 等所有实体的公共属性。
|   `-- EntityType.java        # **实体类型枚举**：如 `STAR`, `PLANET`, `SHIP` 等，用于多态和逻辑分支。
|
|-- government/                # **政体（Government）**：用于描述国家的统治形式与特性（数据定义）。
|   `-- GovernmentDef.java     # **政体定义**：描述政体的基础信息与 modifiers（数据驱动修正）。
|
|-- nation/                    # **国家/文明（Nation）**
|   |-- NationDef.java         # **国家定义**：从 JSON 加载的国家/文明设定。
|   `-- design/                # **玩家设计（Player Design）**：与玩家自定义内容相关。
|       |-- PlayerNationDesign.java # 玩家设计的国家数据模型。
|       `-- NationDesignRepository.java # 玩家国家设计的存储/读取仓库。
|
|-- sim/                       # **模拟层（Simulation）**：负责游戏的时间推进与时钟管理。
|   |-- SimulationClock.java   # **模拟时钟**：处理 `simulationTick` 与游戏内时间（`dtGameHours`）的转换与推进，是游戏世界演化的心跳。
|   `-- SimulationTime.java    # **模拟时间容器**：持有当前的 `tick`, `gameDatetimeDay`, `accGameHoursInDay` 等。
|
|-- species/                   # **物种（Species）**：用于描述可被国家选择/主导的智慧物种（数据定义，占位）。
|   `-- SpeciesDef.java        # **物种定义**：物种基础信息与特质 id 列表（占位）。
|
|-- tech/                      # **科技（Technology）**：用于定义科技条目与基础信息（占位）。
|   `-- TechDef.java           # **科技定义**：科技基础信息（占位），未来可扩展前置科技、效果等。
|
|-- state/                     # **游戏状态（State）**：权威状态容器与对外发布的只读快照，是“读写分离”的核心。
|   |-- snapshot/              # **状态快照 DTO**：用于网络传输的、扁平化的只读数据结构。这是 `game` 模块与外界（如 `webnet`）的数据契约。
|   |   |-- EntitySnapshot.java     # **实体快照**：核心 DTO，包含多态的 `details`，用于向前端描述一个实体（行星轨道/纹理等已扁平化在 PlanetDetails 中）。
|   |   |-- StarSnapshot.java       # (未使用) 旧版恒星快照。
|   |-- DailySettlementState.java # **每日结算状态**：只读快照，用于 UI 展示固定结算周期的数据（经济、人口等）。
|   |-- DailySettlementStateBuffer.java # **每日结算状态的发布容器**：在跨日时更新 `active` 状态。
|   |-- RealTimeWorldState.java   # **实时世界状态**：只读快照，用于 UI/网络，包含实体列表与空间索引，每 `tick` 更新。
|   |-- RealTimeWorldStateBuffer.java # **实时世界状态的双缓冲**：实现模拟与读取分离，`game` 模块写入 `inactive`，`webnet` 读取 `active`，通过 `swap` 无锁发布。
|   `-- WorldState.java          # **唯一权威世界状态容器**：持有 `AstroData` / `WorldMap` 等所有**可变**的权威状态，只允许模拟层（`sim`）修改。
|
`-- world/                     # **世界（World）**：负责世界地图的生成、坐标系与尺度常量。
    |-- hex/                   # **六边形网格（Hex Grid）**：星区坐标与数学工具。
    |   |-- HexMath.java          # 六边形数学/转换工具。
    |   `-- SectorCoord.java      # **星区坐标**：使用 axial(q,r) 坐标系。
    |-- Vec2d.java             # **二维向量**（double）：用于权威世界坐标。
    |-- WorldConstants.java    # **世界常量**：定义 GU/AU/LY 换算、星区尺寸等权威尺度，是所有空间计算的基准。
    |-- WorldGenConfig.java    # **世界生成配置**：如世界半径、种子等。
    |-- WorldGenerator.java    # **世界生成器**：根据配置生成 `WorldMap`，仅在世界创建时调用。
    |-- WorldHexLayout.java    # **世界六边形布局换算**：提供星区坐标到世界坐标（GU）的中心点换算。
    |-- WorldMap.java          # **世界地图**：持有所有星区（`WorldSector`）的容器。
    `-- WorldSector.java       # **世界星区**：六边形地图的基本单元。

|-- ship/                     # **舰船（Ship）**：舰船实体、组件、拼装、移动、战斗等权威模拟。
|   |-- def/                  # **舰船数据定义**：船体/组件等 JSON 定义与仓库。
|   |   |-- ShipAssetRepository.java # **舰船资产仓库**：负责加载所有舰船相关的 JSON 定义。
|   |   |-- ShipModuleDef.java       # **舰船模块定义**：舰船组件（武器、引擎等）的数据模型。
|   |   `-- ShipModulesFile.java     # **舰船模块文件模型**：用于承载一组 `ShipModuleDef` 的文件级数据结构。
|   |-- design/               # **舰船设计**：玩家自定义舰船设计的存储与管理。
|   |   `-- ShipDesignRepository.java # **舰船设计仓库**：玩家舰船设计的存储/读取仓库。
|   |-- ShipBody.java         # **舰船实体**：权威的舰船对象，继承自 `Entity`。
|   |-- ShipComponent.java    # **舰船组件实例**：舰船上已装配组件的运行时状态。
|   |-- ShipDesign.java       # **舰船设计蓝图**：玩家设计的舰船蓝图，包含模块 ID 列表。
|   `-- fleet/                # **舰队（Fleet）（规划中）**：舰队聚合根、舰队命令、舰队 AI。
|
|-- planet/                   # **星球与城市（Planet/City）**：行星地表划分、城市、资源点与生产力系统的权威模拟喵。
|   |-- PlanetSurface.java    # **行星地表组件**：管理地表区域、城市、资源点的聚合根组件喵。
|   |-- def/                  # **行星数据定义**：从 JSON 资产加载的数据模型，只读喵。
|   |   |-- PlanetAssetRepository.java # **行星资产仓库**：负责加载所有行星相关的 JSON 定义喵。
|   |   |-- SurfaceRegionTypeDef.java  # **地表区域类型定义**：大陆/海洋等区域类型的配置喵。
|   |   |-- CityStageDef.java          # **城市阶段定义**：前哨殖民地→巨型都市的成长阶段配置喵。
|   |   |-- CitySpecializationDef.java # **城市专精定义**：科研/采矿/工业等专精的生产力分配配置喵。
|   |   `-- ResourceTypeDef.java       # **资源类型定义**：矿产/农业/景观等资源点的配置喵。
|   |-- surface/              # **地表区域**：行星地表划分与地貌的权威模型喵。
|   |   |-- SurfaceRegion.java    # **地表区域实体**：大陆或海洋区域，包含可开发空间和次级地貌喵。
|   |-- SurfaceGenerator.java # **地表生成器**：基于 PlanetTypeDef.surfaceRegionWeights 确定性生成 SurfaceRegion 列表喵。
|   `-- SubSurfaceFeature.java # **次级地貌实体**：山脉/平原/浅海等地貌，影响资源发现倾向喵。
|   |-- city/                 # **城市系统**：宏观城市建设的权威模型喵。
|   |   `-- City.java         # **城市实体**：城市阶段、规模、专精、人口、生产力的权威状态喵。
|   |-- resource/             # **资源系统**：自然资源点的权威模型喵。
|   |   `-- ResourceSite.java # **资源点实体**：矿产/农业/景观等资源点，提供生产力或吸引力加成喵。
|   `-- production/           # **生产力系统**：城市生产力计算与分配的权威模型喵。
|       |-- ProductionAllocation.java    # **生产力分配**：90%专精生产力+10%通用生产力的分配结果喵。
|       `-- CityProductionCalculator.java # **城市生产力计算器**：计算劳动力+自然资源生产力，按专精分配喵。
|
|-- economy/                  # **经济与资源（Economy）（规划中）**：资源池、产出/消耗、贸易、市场等。
|   `-- def/                  # **经济数据定义（规划中）**：资源/市场/贸易路线等 JSON 定义与仓库。
|
|-- politics/                 # **政治与外交（Politics/Diplomacy）（规划中）**：政体/政策/派系/外交关系等。
|   `-- def/                  # **政治数据定义（规划中）**：政策/派系/外交关系类型等 JSON 定义与仓库。
|
|-- event/                    # **事件与任务（Event/Quest）（规划中）**：事件模板、触发器、任务与实例。
|   `-- def/                  # **事件数据定义（规划中）**：事件/任务/触发器的 JSON 定义与仓库。
|
|-- ai/                       # **AI（规划中）**：国家/舰队 AI、行为树/策略画像等（仅生成命令，不直接改权威状态）。
|   `-- def/                  # **AI 数据定义（规划中）**：AI 个性/行为树/战略画像的 JSON 定义与仓库。
