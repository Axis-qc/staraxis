# StarAxis 文档索引\n\n本文档目录采用“当前规范 + 原生客户端架构 + 游戏设计 + 历史计划归档”的结构。\n\n## 当前权威文档\n\n- `项目规范.md`：开发、架构、工作流、验证和目录规范。\n- `架构设计.md`：当前原生客户端主架构，包含 `lwjgl3 -> client -> ui + game` 链路。\n- `游戏大纲.md`：游戏玩法、系统设计、世界观与核心规则。\n- `术语对齐.md`：项目统一术语表，新增概念先在这里定义。\n- `PLAN.md`：阶段实施计划，执行前需要按当前原生客户端架构复核。\n\n## 模块内文档\n\n- `game/**/文件结构.md`：游戏核心模拟模块局部结构。\n- `ui/**/readme.md`：原生 UI 层局部说明。\n- `web/src/API文档.md`、`webnet/src/API文档.md`：Web 版辅助/历史链路说明，不作为当前主客户端架构依据。\n\n## 历史计划归档\n\n- `superpowers/plans/` 保存历史实施计划。\n- Web 快照、前端本地模拟、双逻辑帧插值等计划属于 Web 版历史/辅助方案。\n- 若历史计划与 `架构设计.md` 冲突，以 `架构设计.md` 为准。\n\n## 当前架构一句话\n\n当前主线是原生 LibGDX 客户端：`lwjgl3` 负责桌面启动，`client` 负责应用生命周期和主循环，`ui` 负责 Scene2D 界面，`game` 负责纯 Java 游戏模拟与权威规则。\n
