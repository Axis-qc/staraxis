# 开发文档总目录（核心入口）

> 本目录是 StarAxis 项目的“开发口径入口”。所有规则、口径、示例、系统边界与术语对齐，均以本目录链接为准。

## 使用说明

- **权威性**：若本文档链接的开发文档与其他草案/笔记存在冲突，以本文档链接到的开发文档为准，并在对应文档注明差异来源。
- **范围**：本目录只做“入口 + 结论摘要 + 跳转”，细节放在各功能文档内。
- **重要性标记**：
  - **必读**：所有开发者都应先读（项目硬边界/统一口径）。
  - **常用**：实现某系统/功能时高频查阅。
  - **参考**：低频查阅或备选方案。
  - **草案**：未定稿内容，可能随实现调整。
