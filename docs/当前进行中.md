#### 迁移策略
- **不做旧代码兼容过渡**：新代码直接替代旧代码，确认无依赖后立即删除旧文件
- 旧 hex 相关代码（`Vec2d`、`SectorCoord`、`WorldHexLayout`、`WorldSector`、`WorldMap` 等）在新版对应模块验证通过后直接删除
- 旧 2D 渲染器（`NativeWorldRenderer` 的 `OrthographicCamera` + `ShapeRenderer` 部分）在 3D 渲染管线验证通过后直接删除

#### 核心方向
将世界从 hex 二维网格升级为真实 3D 宇宙空间：
- Galaxy/System 双视图手动切换（10万^3 坐标盒，无极端坐标）
- 几何小图标渲染（八面体/球体/锥体），星球用纯色球体
- 开普勒轨道力学（二体近似，确定性模拟）
- 原生 OpenGL（PerspectiveCamera + ModelBatch）
- 不需要 CRR，不需要对数深度缓冲

#### 实施顺序
**先打通纯渲染链路，再接入游戏逻辑。** 阶段 A/B 不涉及时间推进、实体系统、命令系统等游戏逻辑，只做数据生成 + 3D 渲染。

- [ ] 新建 `game/.../space/OrbitalElements.java`
  ```java
  public record OrbitalElements(
      double semiMajorAxis,      // a，半长轴 (GU)
      double eccentricity,       // e，偏心率 [0, 1)
      double inclination,        // i，轨道倾角 (弧度)
      double longitudeOfAscendingNode,  // Ω，升交点经度 (弧度)
      double argumentOfPeriapsis,       // ω，近心点幅角 (弧度)
      double meanAnomalyAtEpoch,        // M0，历元平近点角 (弧度)
      double epoch,              // t0，历元时间 (游戏秒)
      double period              // T，轨道周期 (游戏秒)
  ) {}
  ```
