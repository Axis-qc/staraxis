# 资源与产业链

> 目标：定义资源分级、生产配方、产出来源和基础流转关系，为数据驱动与平衡提供一致基线。

## 1. 资源分级（Tier）

- 初级资源（Tier 1 / Primary）：直接采集
- 中级资源（Tier 2 / Intermediate）：由初级加工
- 高级资源（Tier 3 / Advanced）：战略制品

## 2. 生产配方（Recipe）

- **概念**：定义了“输入”与“输出”的转换关系，是所有生产活动的基础。
- **数据结构（口径）**：
  ```typescript
  type Recipe = {
    recipeId: string;
    inputs: { resourceId: string; amount: number }[];
    outputs: { resourceId: string; amount: number }[];
    workforce: number; // 需要的岗位数量
    buildingType?: string; // 必须在特定建筑中生产
  }
  ```

## 3. 产出来源 (Source of Production)

- **核心来源**：所有地表资源的产出均来自**城市**及其内部的**岗位 (Jobs)**，这些岗位应用了特定的**生产配方**。
- **影响因素**：
  - **城市规模与发展水平**：决定了可用的岗位类型和数量，以及能支持的建筑类型。
  - **地表特征**：城市所在的“大陆”或“海洋”及其“次级地形”（如山脉、浅海）会为特定类型的资源产出提供加成。例如，建在“山脉”地形上的城市在矿物产出上会有加成。
  - **轨道设施**：部分资源（如气态资源）来自轨道采集平台，它们也遵循类似的生产逻辑。

## 4. 最小资源链路（示例口径）

- 矿物 → 钢铁（初级 → 中级）
- 钢铁 → 机械零件（中级 → 高级/或中级）

> 注：具体资源表与配方属于数据驱动内容，不在本文档写死完整清单；本文档只定义分级与链路表达方式。

## 5. 字段口径（建议）

- 产出：`production`
- 消耗：`consumption`
- 维护：`maintenance`
- 库存：`stockpile`
- 进出口：`imports` / `exports`
