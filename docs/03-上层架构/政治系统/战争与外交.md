# 战争与外交

> 目标：定义战争中的占领、赔款规则，以及国家间的信用体系，为外交和军事互动提供明确的口径。

## 1. 战争 (War)

### 1.1 占领 (Occupation)

- **核心规则**：当一个星球被敌方占领时，其所有权并未转移，但其产出和管理权会发生变化。
- **开支与产出**：
  - **占领方**：承担该星球所有的**维护开支**（`maintenance`），包括建筑、舰队（如果停靠在该星球）的维护费。
  - **被占领方**：仍然需要承担该星球的人口消耗（`consumption`）。
  - **产出归属**：占领方**仅能获取**该星球当日结算后的**净盈余资源**。如果星球产出为负（赤字），占领方需要从自己的国库中调拨资源来填补，否则占领星球上的建筑会停工。

### 1.2 赔款 (Reparations)

- **目的**：增加战争的后果感，使战败的代价更加沉重。
- **计算口径**：
  - 赔款的总额应基于战败方在战争期间**损失的所有舰船和建筑**的**建造成本**来计算。
  - **惩罚性乘数**：为增加后果感，赔款总额将乘以一个惩罚性系数，例如 **2倍**。
    `赔款总额 = (损失舰船总成本 + 损失建筑总成本) * 2`
  - **支付方式**：赔款可以分期支付，在和平条约中约定每月的支付金额和持续时间。

## 2. 外交 (Diplomacy)

### 2.1 信用体系 (Credit System)

- **概念**：一个量化的分数，用于衡量一个国家在星际社会中的信誉。信用分数的高低会直接影响其外交行为的成功率和贸易条件。
- **分数范围（口径）**：例如，-1000（背信弃义）到 +1000（值得信赖）。

### 2.2 信用变化规则

- **增加信用**：
  -   **履行条约**：成功完成长期贸易协定或防御同盟。
  -   **解放星球**：将星球从压迫者手中解放，并归还给原所有者或赋予其独立。
  -   **应对星际危机**：在全局危机中做出贡献。

- **降低信用**：
  -   **背弃盟约**：单方面撕毁防御同盟、互不侵犯条约等。
  -   **无理由宣战**：在没有合法战争借口（Casus Belli）的情况下发动突袭。
  -   **违反星际法**：使用被星际公约禁止的武器（如行星毁灭武器）。

### 2.3 信用影响

- **交易接受度**：信用分数越高，其他国家越愿意与你进行贸易，并可能提供更优惠的条件。
- **外交成功率**：信用分数越高，签订同盟、达成联邦等外交提议的成功率越高。
- **贷款利率（如果引入星际银行概念）**：信用分数越高，能获得的贷款额度越高，利率越低。
- **星际制裁**：信用分数过低可能会引发星际社会的集体谴责或制裁。
