# 星区类型

> 目标：统一星区（六边形单元）的类型枚举口径、基础效果与生成职责边界。

## 1. 星区类型列表（规范）

| 星区类型（中文） | 建议英文ID | 核心内容 | 关键效果/约束（口径） |
|------------------|-----------|----------|------------------------|
| 恒星系星区 | star-system | 包含一个恒星系（恒星/行星/轨道设施） | 允许进入恒星系视角；可产生轨道资源点 |
| 深空星区 | deep-space | 空无一物/稀疏事件 | 适合航道、伏击；通常无固定产出 |
| 星云星区 | nebula | 星云环境 | 干扰探测；可产特殊资源（需数据驱动定义） |
| 风暴星区 | storm | 宇宙风暴环境 | 进入可能受损/受Debuff（口径） |
| 深空资源星区 | deep-resource | 额外资源点 | 补充稀缺资源；不一定有恒星系 |

## 2. 职责边界

- 星区类型在“分配阶段”只确定 **类型ID**
- 在“生成阶段”根据类型ID决定生成器链（恒星系/星云/资源点等）

## 3. 术语与一致性

- 星区最小单位统一称为：**星区（SectorHex）**
- “星域（Region）”是多个星区的集合概念，不得混用
