核心基准，渲染，世界大小全部依次为权威基准，任何渲染都要遵从此核心逻辑！！！


- **最重要：1:100,000 缩小的宇宙（权威坐标单位）**
  - 游戏内采用 **1:100,000** 的现实尺度缩放。
  - 定义 **权威坐标单位**：`1 坐标单位（Game Unit, GU） = 100,000 米（m）`。
  - 游戏的“世界坐标/数据坐标”应直接使用 `GU` 作为单位。

- `GAME_UNIT_IN_METERS = 100_000`
- `AU_IN_METERS = 1_495_978.70700` //1AU,1天文单位的游戏内实际长度
- `LY_IN_METERS = 94_607_304_725.80800`//1LY，1光年的游戏内实际长度

- 六边形布局：**pointy-top（尖顶）**（本文件后续所有 hex 公式基于该约定）

- **权威 1.0 缩放（渲染基准）**：将 `zoom=1.0` 作为全局渲染换算的**权威基准**。
  - 在 `zoom=1.0` 下：屏幕 **1 像素（px）** 严格对应 **1 坐标单位（GU）**。
  - `1px = 1GU = 100,000m`（at `zoom=1.0`）
  - **缩放语义**：`zoom` 仅表示“视野缩放/画面缩放”。
    - `guPerPixel(z) = z`
    - `screenDeltaPx = worldDeltaGU / guPerPixel(z)`

- **举例（用于校验数据/渲染一致性）**
  - **距离换算**：地球与太阳真实距离约 `149,597,870,700m`。
    - 换算为游戏内：`149,597,870,700 / 100,000 = 1,495,978.707 GU`。
    - 若以太阳为原点 `(0,0)`，并把行星沿 `+X` 轴排列，则地球位置应约为：`(x=1,495,978.707, y=0) GU`。
  - **尺寸换算**：地球真实直径 `12,742,000m`。
    - 换算为游戏内直径：`12,742,000 / 100,000 = 127.42 GU`。
    - 在 `zoom=1.0` 渲染基准下，地球直径应约为 `127.42px`；在 `zoom=2.0` 下约为 `63.71px`。
