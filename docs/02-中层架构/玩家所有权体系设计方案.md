# 玩家所有权体系设计方案

> 对应需求：Player 从纯字符串标识升级为一级对象，支持个人直接拥有实体 + 个人资产与国家资产自由转换

---

## 1. 现状与问题

### 当前链路

```
playerId(str) → NationManager.playerToNation → NationState → Entity.ownerNationId
```

- Player 仅为字符串 ID，无独立状态对象
- 所有权链路完全以国家为中心，**跳过个人所有权**
- `Entity` 只有 `ownerNationId`，无法区分"我的船"和"国家的船"
- 建国流程中自动将星系天体归属到国家，没有"我先拥有→再选择贡献给国家"的环节
- 单人模式下 `playerId` 概念淡化，所有权体系两套逻辑

### 缺失能力

| 场景 | 当前行为 | 期望行为 |
|------|---------|---------|
| 玩家只有舰队没建国 | N/A，玩家必须绑定国家 | 玩家的舰队直接归 `ownerPlayerId` |
| 玩家捐献舰船给国家 | 无区分 | 从个人资产转为国家资产 |
| 叛国/脱离国家带走个人舰队 | 无区分 | 保留个人资产，放弃国家资产 |
| 多人同国区分"我的"和"国家的" | 全部是国家的 | 个人资产 / 国家资产分层 |
| 建国时选择哪些资产转入国家 | 自动全转 | 玩家保留所有权，可选地捐献 |

---

## 2. 设计目标

1. **Player 成为一级概念**：`PlayerState` 类似 `NationState`，拥有独立的状态和资产表
2. **Entity 双归属字段**：`ownerPlayerId` + `ownerNationId`，均可为 null，两者自由组合
3. **自由资产转移**：支持 Player ↔ Nation 之间的双向所有权移动
4. **建国不自动转移**：创建国家时，玩家的个人资产**不自动归属国家**；由玩家操作"捐献"完成转移
5. **权威链路不变**：所有所有权变更仍走 `AssetManager`（原 `NationAssetManager` 升级），保证一致性

---

## 3. 详细设计

### 3.1 PlayerState（新增）

用于存储玩家的所有游戏内运行时状态，和 `NationState` 平级。

```java
package staraxis.game.player;

/**
 * PlayerState（玩家运行时状态）
 *
 * 玩家的一级状态对象。一个 PlayerState 对应一个真实/联机玩家。
 */
public class PlayerState {

    /** 玩家唯一标识（p_ 开头的 UUID）。 */
    public final String playerId;

    /** 玩家显示名（从 Account 同步）。 */
    public String displayName;

    /** 所属国家ID（可选，无国家时为 null）。 */
    public String nationId;

    /** 个人直接资产表：EntityType -> 该类型下该玩家直接拥有的实体ID集合。 */
    public final Map<EntityType, Set<Long>> ownedEntityIdsByType = new HashMap<>();

    // --- 生命周期标志 ---

    /** 是否已建国（是否曾经/当前拥有国家）。 */
    public boolean hasFoundedNation = false;

    /**
     * 添加实体到个人资产表。
     */
    public void addOwnedEntity(Entity entity);

    /**
     * 从个人资产表移除实体。
     */
    public void removeOwnedEntity(Entity entity);

    /**
     * 获取个人在指定类型下的实体ID集合。
     */
    public Set<Long> getOwnedEntityIds(EntityType type);
}
```

### 3.2 PlayerManager（新增）

```java
package staraxis.game.player;

/**
 * PlayerManager（玩家管理器）
 *
 * 集中管理所有玩家的运行时状态。
 * 与 NationManager 平行，共同构成所有权管理层。
 */
public class PlayerManager {

    /** playerId -> PlayerState 映射。 */
    private final Map<String, PlayerState> playerStates = new HashMap<>();

    /** 注册玩家（创建运行时状态）。 */
    public PlayerState registerPlayer(String playerId);

    /** 获取玩家状态。 */
    public PlayerState getPlayerState(String playerId);

    /** 检查玩家是否存在。 */
    public boolean hasPlayer(String playerId);

    /** 获取所有玩家ID。 */
    public Set<String> getAllPlayerIds();

    /** 获取所有玩家状态。 */
    public Collection<PlayerState> getAllPlayerStates();

    /** 设置玩家所属国家。 */
    public void setPlayerNation(String playerId, String nationId);

    /** 获取玩家所属国家。 */
    public String getPlayerNation(String playerId);

    /** 解除玩家与国家关联（保留个人资产）。 */
    public void removePlayerFromNation(String playerId);

    /** 清除所有玩家状态。 */
    public void clear();
}
```

### 3.3 Entity 变更

在现有字段基础上增加 `ownerPlayerId`：

```java
// Entity.java — 新增字段
/** 所属玩家ID（可选）。无归属时为 null。 */
public String ownerPlayerId;
```

**所有权组合规则：**

| ownerPlayerId | ownerNationId | 语义 |
|:---:|:---:|------|
| null | null | 无主实体（太空垃圾、野生海盗等） |
| set | null | 玩家个人资产：纯个人拥有，不挂靠任何国家 |
| null | set | 国家资产：属于国家公共资产，不归个人 |
| set | set | 个人受国家管辖资产：归个人拥有但属于国家体系（例如国家将领的旗舰） |

### 3.4 AssetManager 重构（原 NationAssetManager 升级）

将 `NationAssetManager` 升级为 `AssetManager`，统一管理 Player 和 Nation 两个维度的所有权操作。

```java
package staraxis.game.nation;

/**
 * AssetManager（资产管理器）
 *
 * 统一管理 Player 和 Nation 两个维度的实体所有权：
 * - Entity.ownerPlayerId ← PlayerState.ownedEntityIdsByType
 * - Entity.ownerNationId ← NationState.ownedEntityIdsByType
 *
 * 所有所有权变更必须通过本管理器完成，禁止外部直接修改归属字段。
 */
public class AssetManager {

    // ======== 玩家所有权操作 ========

    /** 分配实体给玩家。设置 ownerPlayerId，加入 PlayerState。 */
    public void assignToPlayer(long entityId, String playerId);

    /** 批量分配实体给玩家。 */
    public void assignToPlayer(Collection<Long> entityIds, String playerId);

    /** 释放实体的玩家所有权（ownerPlayerId = null）。 */
    public void releasePlayerOwnership(long entityId);

    // ======== 国家所有权操作 ========

    /** 分配实体给国家（等价于原 assignEntityToNation）。 */
    public void assignToNation(long entityId, String nationId);

    /** 批量分配实体给国家。 */
    public void assignToNation(Collection<Long> entityIds, String nationId);

    /** 释放实体的国家所有权（ownerNationId = null）。 */
    public void releaseNationOwnership(long entityId);

    // ======== 跨层级转移 ========

    /**
     * 玩家捐献实体给国家。
     * 效果：ownerPlayerId 保留，ownerNationId 设为 nationId。
     * 资源同时出现在 PlayerState 和 NationState 资产表中。
     */
    public void donateToNation(long entityId, String playerId, String nationId);

    /**
     * 国家授予实体给玩家。
     * 效果：ownerNationId 保留，ownerPlayerId 设为 playerId。
     * 资源同时出现在 NationState 和 PlayerState 资产表中。
     */
    public void grantToPlayer(long entityId, String nationId, String playerId);

    // ======== 综合释放 ========

    /** 完全释放实体所有权（两个 owner 均置 null）。 */
    public void releaseAllOwnership(long entityId);

    // ======== 查询 ========

    /** 查询玩家直接拥有的实体ID集合。 */
    public Set<Long> getPlayerOwnedEntityIds(String playerId, EntityType type);

    /** 查询某实体是否归属于指定玩家。 */
    public boolean isOwnedByPlayer(long entityId, String playerId);

    /** 查询某实体是否归属于指定国家。 */
    public boolean isOwnedByNation(long entityId, String nationId);
}
```

**核心一致性约束：**

- `assignToPlayer()`: 设 `Entity.ownerPlayerId` + 加入 `PlayerState.ownedEntityIdsByType`
- `assignToNation()`: 设 `Entity.ownerNationId` + 加入 `NationState.ownedEntityIdsByType`
- `donateToNation()`: 玩家表保留 + 国家表新增（`ownerPlayerId` 保留，`ownerNationId` 设置）
- `grantToPlayer()`: 国家表保留 + 玩家表新增（`ownerNationId` 保留，`ownerPlayerId` 设置）
- 释放操作：双表均移除

### 3.5 NationManager 变更

```java
// NationManager — 调整
- assignPlayerToNation(playerId, nationId)
    → 改为通过 PlayerManager.setPlayerNation + AssetManager 配合完成
    → 不自动转移个人资产

- removePlayerFromNation(playerId)
    → 保留个人资产（ownerPlayerId 不动）
    → 仅移除国家关联
```

**关键变更**：`NationManager.assignPlayerToNation()` 从"玩家加入国家"变为**仅仅建立归属关系，不碰资产**。资产的跨层转移由 `AssetManager.donateToNation()` 和 `AssetManager.grantToPlayer()` 显式触发。

### 3.7 StarSystem.ownerNationId 说明

`StarSystem` 自身有 `ownerNationId` 字段和 `assignOwnership()` 级联方法（遍历设置所有恒星/行星的 `ownerNationId`）。**`StarSystem` 不是 Entity，没有 `ownerPlayerId`**。

当前阶段：开局全部置 null，不分配任何系统级归属。

后续阶段由 `AssetManager` 统一处理——`assignToPlayer`/`assignToNation` 操作实体时，是否需要反向传播到 `StarSystem` 层，待开局流程设计时再决定。

## 4. 开局流程（当前：清空状态）

**开局不做任何所有权分配。** `newGame()` 只生成世界，所有实体保持无主。

```
newGame(cfg)
  → 生成恒星系、行星、天体（所有 Entity.ownerPlayerId = null, ownerNationId = null）
  → 初始化 WorldState（含 PlayerManager、AssetManager、NationManager 等）
  // 以下全部不做：
  // ✗ 不注册玩家
  // ✗ 不注册国家
  // ✗ 不分配任何实体归属
  // ✗ 不绑定出生星系
  // ✗ 不调用任何 assignPlayerToNation / assignEntityToNation
```

开局流程（选舰队→殖民→建国）待后续统一设计，当前阶段只搭建所有权基础设施，不接入具体流程。
