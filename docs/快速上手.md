---

## 核心架构

```
game        权威游戏逻辑、WorldState、模拟推进、Command 执行、只读快照发布
client+ui   原生客户端、libGDX/OpenGL 世界画面渲染、输入、相机、Scene2D UI
lwjgl3      桌面端启动器，创建窗口启动 client
webnet      联机网关：账号/权限/房间/AI API/原生联机同步
web         AI 控制台 / 管理控制台（不渲染高频世界画面）
```

**关键原则**：`game` 是唯一写入口，所有修改必须走 `Command`；渲染只读快照，不直接持有权威对象。

## 硬规则

1. **模拟层权威**：所有游戏结果逻辑只在 `game` 执行
2. **唯一写入口**：任何层不得直接写 `WorldState`，必须转 `Command`
3. **确定性优先**：相同输入 → 相同结果，便于存档/回放/联机对账
4. **模拟时间驱动**：推进绑定 `simulationTick`，不由 FPS 驱动
5. **双快照**：`DailySettlementState`（经济/人口）+ `RealTimeWorldState`（战斗/移动）
6. **渲染只读**：渲染层只读快照，不持有/修改权威实体
7. **webnet 不做规则**：只做网络/权限/API，不实现游戏规则
8. **权限隔离**：AI/API/联机请求必须校验 token、playerId、nationId、视野
9. **数据驱动**：内容由外部数据定义，禁止魔法数字和硬编码
10. **先检索再实现**：新增前搜索现有代码，避免重复

## 运行模式

### 单机 / 本机 Host

```
lwjgl3 → client → StarAxisGameRuntime → renderer(runtime.getRealTimeWorldStateReadonly())
                                        → input/UI → Command → runtime.submitCommand(...)
```

启动：`./gradlew run`（等价底层入口：`./gradlew :lwjgl3:run`）

### Dedicated Server

```
server: game(StarAxisGameRuntime) + webnet(账号/权限/房间/AI API)
native client: 接收 NativeWorldFrame → 渲染 → 发送 PlayerCommandRequest
web: AI 控制台，调用 webnet AI/API
```

### web/webnet 调试

- `./gradlew :webnet:run` — 启动后端
- `cd web && npm run dev` — 前端 dev server
- `cd web && npm run build` — 构建前端
