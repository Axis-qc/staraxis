## 问题与解决方案

### 问题1：星空背景在 Scene2D 内偏移到左下角

- **原因分析**：StarfieldBackground 在 Stack → Container 层级内，ShapeRenderer 和 Batch 的变换矩阵不一致。
- **解决方案**：从 JSON 布局中移除 starfield 节点，改为在 `ClientGame.render()` 中直接用屏幕坐标渲染，`setToOrtho2D(0, 0, w, h)` 独立投影。

### 问题2：增量模式字体崩溃 `Couldn't set size for font`

- **原因分析**：`incremental=true` 时 BitmapFont 持有 FreeTypeFontGenerator 引用用于按需生成字形，但 `finally { generator.dispose() }` 在生成后立即销毁引擎。
- **解决方案**：成功时不 dispose，将 generator 存入 `incrementalGenerators` 列表保活；退出时调用 `FontProvider.disposeAllIncremental()`。

### 问题3：`pageSize` 字段不存在于 FreeTypeFontParameter

- **原因分析**：libGDX 1.14.0 的 `FreeTypeFontParameter` 没有 `pageSize` 字段。
- **解决方案**：改用 `incremental=true` 从根源解决纹理页容量问题。

## 技术要点

- **三层分离架构**：效果（视觉参数 JSON）→ 组件（Widget Java）→ 布局（position JSON）。JSON 只写 `type` + `effect` + `text/onClick` + `cell`。
- **数据绑定**：`repeat` + `dataSource` 自动从 DataProvider 填充列表；`${key}` 占位符替换模板。
- **增量字体**：`incremental=true` 避免 CJK 字形溢出纹理页，代价是 generator 需保持存活直到应用退出。
- **星空渲染**：独立于 Scene2D，在 `stage.draw()` 前用 ShapeRenderer 屏幕坐标渲染，不受变换管线影响。
