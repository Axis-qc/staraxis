### 修复记录（阶段A首次运行后回馈）

#### Galaxy 全黑
- **原因**：`StarBatchRenderer` 的自定义着色器未设置 `u_projViewTrans` uniform
- **修复**：在 `end()` 中手动 `shader.setUniformMatrix()`

#### System 竖着（行星轨道垂直）
- **原因**：`OrbitSolver` 轨道面在 XY 平面（天文学标准），渲染期望在 XZ 水平面
- **修复**：修改 `OrbitSolver.rotateToGalaxyFrame()` 接收 `(xLocal, zLocal)`，旋转矩阵重新推导
- **同步**：`OrbitRingMesh` 使用相同旋转矩阵，移除渲染端坐标变换

#### Galaxy 恒星只显示一个点
- **原因**：`GL_POINTS` 渲染方像素点
- **修复**：改用 `ModelBatch` + 固定大小球体模型（半径40 GU，8x6 segments）

#### Galaxy 鼠标选中不准
- **原因**：射线与 Y=0 平面求交 -> 找 XZ 最近恒星（忽略 Y 轴）
- **修复**：用 `Intersector.intersectRayBounds` 直接检测恒星球体 AABB 碰撞盒

#### 遗留优化点
- `pick()` 中 `calculateBoundingBox` 每帧对 5000 个实例重复计算（应缓存 model-space bounds）
- `render()` 和 `pick()` 在同一帧重复设置 transform

### 阶段 B 实施 -- 坐标改造 + 渲染器接入真实状态

#### 时间

#### 坐标系统 2D→3D
- `Entity.posWorldGU/velWorldGU`：`Vec2d` → `SpacePosition`
- `ShipBody.movementTarget`：`Vec2d` → `SpacePosition`
- `MovementCommand` 全部坐标字段：`Vec2d` → `SpacePosition`
- `EntitySnapshot` / `ShipDetails` / `MovementCommandDetails`：`Vec2d` → `SpacePosition`
- 星系盘面映射：`Vec2d(x, y)` → `SpacePosition(x, 0, y)`，旧 `.y()` → 新 `.z()`
- 保留 `Vec2d` 用于 hex 星区网格（`WorldHexLayout` / `WorldSector.centerWorldGU` / `StarSystem.centerWorldGU`）

#### 运动系统适配
- `AbstractShipMovementSystem`：`speedOf(Vec2d)` → `velocity.length()`，`applyVelocity` 使用 `SpacePosition.add()`
- `ShipFullMovementSystem`：全部向量运算从 XY 改为 XZ（`moveDirY`→`moveDirZ`，`targetVelY`→`targetVelZ`，`new Vec2d`→`new SpacePosition`）
- `ShipSimplifiedMovementSystem`：同上改动

#### webnet 适配
- `ShipCommandApi`：`parseVec2`→`parseSpacePos`，`distance(Vec2d,Vec2d)`→`SpacePosition.distanceTo()`，序列化 `toSpacePosMap`（x→x, y→z）
- `SpawnColonyShipCommand`：前端发 x/y → 构造 `SpacePosition(x, 0, y)`
- `WorldSavesApi`：保存时写 posX/posY(posZ)/velX/velY(velZ)，加载时映射旧 posY→z

#### 渲染器接入真实游戏状态
- **Galaxy View**：`StarBatchRenderer` 改为接收 `RealTimeWorldState`，按 `entityType==STAR` 过滤，温度 K→RGB 着色

- **新增**：`client/render/util/TemperatureColor.java` — 黑体色温 RGB 转换
- **ClientGame**：移除 `spaceMode` 切换/`T` 键/合成 `GalaxyData`/`StarSystemGenerator`，默认始终走 3D 渲染管线
