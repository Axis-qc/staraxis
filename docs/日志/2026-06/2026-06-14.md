### 12. 声明式 UI 修改系统讨论

- **背景**：用户询问 mod 能否修改硬编码界面（如 `MainMenuScreen`），讨论了声明式 UI 修改系统的可行性。
- **核心思路**：mod 在 `gamedata/mods/{modId}/ui/patches/` 下放 JSON 文件，声明对某个界面的修改。
- **两种模式**：
  - `add`：在锚点元素的指定位置插入新组件
  - `override`：清空舞台，用新组件树完全替换
- **可行性结论**：完全可行。libGDX 的 Scene2D 支持树形结构操作，已有 `UiParser`/`UiFactory` 可复用，设置界面已有类似 mod 扩展机制。
- **待定问题**：
  - 是否要实现这个系统
  - 如果做，范围是什么（只支持 MainMenu 还是所有 Screen）
  - mod jar 加载是否也要一起做
- **决策**：加入待办队列（中优先级），等 UI 流程稳定后再实现。
