## 第二部分：3D 宇宙架构方案设计

### 方案迭代过程
1. **初版**：hex → 3D Cartesian，开普勒轨道，Octree，Game/System 双视图跳转
2. **修订一（无缝缩放）**：去除视图跳转，改为连续无缝缩放，新增 CRR + 对数深度 + 连续 LOD
3. **修订二（简化范围）**：舰船已是图标，去掉舰船尺度，缩放范围 20 → 15 数量级
4. **修订三（距离压缩）**：真实太空太空旷，采用游戏化距离压缩——轨道等比缩放，星际直接拉近。范围 15 → 7 数量级
5. **修订四（GU 定义）**：GU 从渲染概念回归纯数值坐标单位，game 模块定义，渲染层自决映射

### 最终方案核心指标
- 坐标系：3D Cartesian (x,y,z) GU
- 缩放：7 个数量级，星系全景 ~5e8 GU → 行星近景 ~10^2 GU
- 轨道：开普勒二体近似，轨道周期设计值
- 空间：Octree（12 层，根边长 ~10^9 GU）
- 生成：螺旋臂星系 + 延迟恒星系生成
- 渲染：原生 OpenGL（PerspectiveCamera + 程序化 Mesh + 连续 LOD）
- 周期：4 阶段 6-8 周

### 关键决策
- 不做 N 体引力 / PBR / 行星地表 / web 3D
- 不做无缝缩放（后改为做）→ 最终做无缝缩放但有距离压缩
- 不做存档兼容（开发中无老存档）

### 修改文件
- `ClientGame.java`：添加 T 键切换测试模式

### 开发过程与踩坑
1. **滚轮暴走**：LWJGL3 的 `getDeltaY()` 不自动清零，持续累积 → 改用 Q/E 键盘缩放
2. **镜头倾斜**：`lookAt` 自动重算 up → 手动正交化 `right=direction×Y, up=right×direction`
3. **远距离裁剪**：尝试动态 near/far、极值 near/far、禁用深度测试均无效
4. **CRR 问题**：相机在原点、实体在 -5e8 GU 的极端坐标导致 OpenGL 裁剪异常
5. **最终方案**：放弃 CRR，相机直接放在世界坐标几千 GU 处，所有坐标在 float 精度范围内
6. **ModelBatch 恢复**：小坐标下 ModelBatch 正常工作，3D 球体渲染成功

### 测试场景技术栈
```
ModelBatch（3D 球体）：
  ├── 恒星：24×18 分段金色球体 + 环境光照
  └── 行星：16×12 分段彩色球体（scale 到各自半径）

ShapeRenderer（辅助线）：
  ├── 坐标轴：RGB 三色线，长 500 GU
  ├── 轨道环：128 段线段圆
  └── 背景参考点：十字线网格
```

### 操作方式
| 操作 | 效果 |
|------|------|
| Q / E | 缩放 |
| 左键拖拽 | 旋转（yaw + pitch）|
| 右键拖拽 | 平移 |
| R | 重置视点 |
| T | 切换测试/主菜单 |

### 验证结论
- 坐标比例（恒星 150、行星轨道 500~6000、行星半径 8~55 GU）视觉合理
- ModelBatch + ShapeRenderer 混合渲染管线可行
- CRR 在大尺度下有问题，需在阶段 3 渲染管线中重新设计

## 架构说明

### JSON UI 为主，Java Screen 为辅
实际 UI 渲染流程为：JSON 文件 → JsonScreen → UiParser → UiFactory。所有 JSON 界面已通过 EffectRegistry 实现主题统一：
- `main_menu.json` 使用 `menu_item_primary`、`title_hero`、`version_dim` 等 effect
- `load_game.json` 使用 `menu_item_primary`、`title_white`、`primary_button`
- `nation_select.json` 同上

Java Screen 类仅用于需要复杂交互逻辑的页面（如 WorldSettingsScreen 的表单控件）。

### 控件体系
| 控件类型 | 使用的 Widget | 颜色来源 |
|---------|-------------|---------|
| 标题 | VectorLabel + "title_hero" effect | UiTheme.title |
| 副标题 | VectorLabel + "subtitle_accent" effect | UiTheme.subtitle |
| 菜单项 | MenuEntry + "menu_item_primary" effect | EffectRegistry |
| 按钮 | VectorButton + "primary_button" effect | EffectRegistry |
| 正文 | VectorLabel + UiTheme.text | UiTheme |
| 表单控件 | TextField/SelectBox + 透明样式 | UiTheme |
