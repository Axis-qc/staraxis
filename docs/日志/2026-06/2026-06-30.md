## 问题与解决方案

### 问题1：半透明黑块
- **现象描述**：恒星球出现黑色块
- **原因分析**：alpha 混合开启时深度写入也开着，半透明球写入深度后遮挡后方片元，被剔除的片元成黑块
- **解决方案**：球回退为不透明渲染（alpha=1），关闭 blend，深度测试+深度写入正常开启；远端用 `discard` 跳过
- **验证结果**：黑块消失，球正确遮挡后方

### 问题2：光晕穿透
- **现象描述**：可以透过前方恒星球看到后方的光晕
- **原因分析**：光晕完全关闭深度测试
- **解决方案**：光晕开启深度测试（GL_LEQUAL），被前方球写入的深度遮挡；保持关闭深度写入，光晕间 additive 叠加不互相遮挡
- **验证结果**：前方球正确遮挡后方光晕，光晕间不彼此遮挡

### 问题3：光晕太糊
- **现象描述**：光晕全范围柔和渐变，没有清晰亮核，看起来糊
- **原因分析**：单一 `smoothstep(1.0, 0.0, d)` 从中心到边缘均匀过渡，没有亮核与晕圈的对比
- **解决方案**：拆为两层独立渲染——模糊扩散层（柔和渐变）和锐利发光点层（亮核+外晕），各自独立参数控制
- **验证结果**：既有清晰发光点又有柔和扩散感

### 问题4：光晕大小固定导致远处看不到
- **现象描述**：远处光晕因透视缩小几乎看不见
- **解决方案**：光晕世界尺寸随距离线性放大，5000~8000 从球大小增到满尺寸
- **优化**：最终改为两层独立 sizeScale 参数，灵活调整

## 技术要点

1. **GPU 实例化光晕**：用 billboard quad + `glDrawElementsInstanced` 叠加光晕，与恒星球共用同源数据，GPU 端一次 draw call 一层
2. **LOD 硬切换 + 光晕缩放**：球 `discard` 方式切换无需 alpha 混合，避免半透明深度问题；光晕用线性 `mix(lodFar, shrinkFar)` 控制大小
3. **双层 additive 渲染**：两套 fragment shader 共享顶点逻辑和实例 VBO，先大后小两次 draw call，颜色相加产生复合发光效果
4. **程序化径向渐变**：无需外部贴图，`smoothstep` + 幂律组合实现亮核+外晕+柔和三层效果
5. **深度策略**：球不透明写深度（标准遮挡）；光晕读深度不写深度（被球遮挡，光晕间 additive 叠加不互相遮挡）；GL_LEQUAL 确保恒星球深度与光晕在同一位置时都能通过
