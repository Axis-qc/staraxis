## 📋 使用说明

### 1. 查找日志
- 按日期查找：使用上方索引链接快速定位到具体日期的日志喵。
- 按主题查找：使用浏览器的页面搜索功能（Ctrl+F）查找关键词喵。

### 2. 创建新日志
1. 复制模板文件：`template.md` 喵。
2. 放入对应年月目录 `YYYY-MM/YYYY-MM-DD.md` 喵。
3. 填写当日工作内容喵。
4. 更新本索引文件，在合适位置添加新条目喵。

### 3. 日志规范
- **目录结构**：`YYYY-MM/YYYY-MM-DD.md`（按年月分目录）喵。
- **标题格式**：`# YYYY-MM-DD 喵` 喵。
- **内容结构**：参考模板文件，保持格式统一喵。
- **索引条目**：格式为 `月-日（简述工作内容）`，按日期倒序排列喵。

### 4. 维护提示
- **及时归档**：每日工作结束后应及时创建日志喵。
- **简述清晰**：索引中的简述应能反映主要工作内容喵。
- **链接有效**：确保索引中的相对路径链接正确喵。
