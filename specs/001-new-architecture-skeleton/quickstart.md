# Quickstart: JCEF 主菜单 UI 骨架

## 目标

在本地运行桌面客户端，启动游戏窗口，并在窗口内通过 WebView 展示主菜单。

## 前置条件

- 已安装 JDK 21
- 可使用 Gradle 构建项目
- 已准备好本地 UI 资源目录：`assets/ui/gameui/`

## 运行方式（手工验证）

1. 使用 IDE 导入 Gradle 项目。
2. 运行桌面启动入口（以 `lwjgl3` 模块为准）。
3. 验证启动后是否出现主菜单，并可点击 6 个入口按钮。

## 验收要点

- 启动后 3 秒内可见主菜单与 6 个入口。
- 点击“退出游戏”退出客户端。
- 点击其余入口弹出“开发中”提示。
- UI 资源完全离线加载，无外网依赖。
