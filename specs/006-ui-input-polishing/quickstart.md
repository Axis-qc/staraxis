## Run

在仓库根目录执行：

- `./gradlew :lwjgl3:run`

## Manual Verification Checklist

### 1) 科技感 UI 视觉验收
- 进入“新游戏配置”界面。
- **观察**：
  - 滑动条 (Slider) 是否具备半透明背景和霓虹边框。
  - 文本框 (TextField) 在获取焦点时是否有霓虹高亮效果。
  - 下拉框 (SelectBox) 的展开列表样式是否与主题一致。

### 2) 本地化完整性验收
- 在主界面或配置界面切换语言。
- **验证**：
  - 加载状态（如“生成中...”）是否正确翻译。
  - 错误提示是否正确翻译。
  - 所有新增的标签文本均无硬编码。

### 3) WASD 镜头控制验收
- 进入世界渲染界面 (WorldScreen)。
- **操作**：
  - 按下 `W/A/S/D` 键。
  - **期望**：镜头平滑移动，松开按键后有轻微的惯性滑动停止感。
  - **冲突测试**：在输入框中打字，观察镜头是否不会随之移动。

### 4) 鼠标中心缩放验收
- 将鼠标指向地图上的某个特定六边形。
- **操作**：滚动鼠标滚轮。
- **期望**：该六边形始终保持在鼠标指针下方（或视角向其对焦），缩放平滑无跳变。
