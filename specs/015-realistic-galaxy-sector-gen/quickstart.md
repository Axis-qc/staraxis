# 015 - 真实比例六边形星区与内容分配：快速开始（验收路径）

## 1. 目标

用最短路径验证本特性满足：
- 星区拓扑与数量正确（由半径 R 决定）
- 相邻星区中心距符合 1ly 映射（SC-002）
- 内容类型分配比例满足误差要求（SC-003）
- 同 seed 可复现（SC-004）

## 2. 前置

- 已能运行客户端：`./gradlew :lwjgl3:run`
- F3 调试面板可用（已有 DebugSystem 等）

## 3. 最小配置建议

- 星系大小：R = 8（N = 1 + 3*8*9 = 217，满足 N≥200）
- 内容比例：
  - `star-system`（星系星区）: 0.5
  - `nebula`（星云）: 0.2
  - `deep_space`（深空）: 0.3
- seed：固定一个值（例如 12345）
- 预设：可先为空列表（或仅 1 个 fixed-hex 占用测试）

## 4. 运行与验证

### 4.1 生成并进入星图
1) 进入新游戏开局流程
2) 确认使用上述 R、比例、seed
3) 进入星图界面

### 4.2 验证星区数量
- 通过日志或调试面板统计 sector 数量
- 期望：`N = 1 + 3R(R+1)`

### 4.3 验证真实比例（SC-002）
- 在调试面板中选择任意一对相邻 HexCoord（例如 (0,0) 与 (1,0)）
- 读取两者 worldCenterKm 的距离
- 期望：误差 ≤ 1%

### 4.4 验证分配比例（SC-003）
- 统计 sectors 中 `contentTypeId` 的占比
- 期望：N≥200 时，偏差 ≤ ±10%，且预设占用不被覆盖

### 4.5 验证可复现（SC-004）
- 相同配置+seed 连续生成 3 次
- 期望：布局、分配结果完全一致

## 5. 备注

- 本期恒星系内容为占位符（只验证“这里有星系”），不验证主星/行星生成。
