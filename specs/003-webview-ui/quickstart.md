# Quickstart: WebView 嵌入与开始界面（003）

本 Quickstart 用于在本地快速验证 003 的验收要点：客户端启动后进入开始界面（主菜单），5 个按钮弹“开发中”，退出按钮可退出，WebView 加载失败有兜底。

## 资源准备

- UI 资源根目录：`assets/ui/`
- 允许按模块细分子目录，例如：
  - `assets/ui/start-menu/`
  - `assets/ui/common/`

## 验收步骤（手工）

1. **启动客户端**
   - 启动后进入“开始界面”。
   - 能看到 6 个按钮：新游戏、加载游戏、多人游戏、舰船编辑器、设置、退出游戏。

2. **占位按钮**
   - 点击以下任一按钮：新游戏 / 加载游戏 / 多人游戏 / 舰船编辑器 / 设置。
   - 出现“开发中”提示：
     - 可手动关闭
     - 会自动消失

3. **退出游戏**
   - 点击“退出游戏”。
   - 弹出确认对话框（确认/取消）。
   - 点击“确认”后客户端关闭。

4. **WebView 加载失败兜底**
   - 在可控方式下模拟 UI 资源加载失败（例如临时让开始界面入口资源不可用）。
   - 客户端显示错误页/错误层：
     - 包含错误文案
     - 包含“退出游戏”按钮
   - 点击“退出游戏”后客户端关闭。

## 常见问题排查

- 若出现白屏且无法退出：不满足 FR-W05，需要实现错误层兜底与退出入口。
- 若“开发中”提示无法关闭或不自动消失：不满足 FR-W02。
- 若退出不弹确认或确认后未退出：不满足 FR-W03。
