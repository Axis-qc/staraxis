# Tasks: StarAxis 设定与开发准备文档（Design Bible）

> 所有任务遵循「先可用后完善、先基础后细节、按用户故事独立可验收」原则。

---

## 目标目录结构（必须遵循）

```text
\\staraxis\\开发文档\\
├── 总目录.md                # 核心总览（所有入口）
├── 规范与约定\\            # 命名、术语、时间推进等全局规范
├── 世界系统\\              # 星图/星区/恒星系/坐标与尺度/世界生成
├── 经济系统\\              # 资源、产业链、市场、运输、结算
├── 战斗系统\\              # 舰船、武器、防御、补给、战斗规则
├── 交互系统\\              # 视角分层、可交互对象、信息密度基线
└── 示例\\                  # 可复算示例（坐标、日结算等）
```
