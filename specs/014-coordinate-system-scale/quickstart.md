# Quickstart - 014 基础坐标系与比例尺

本 quickstart 用于快速验证本功能是否接入了**实际渲染**（世界坐标轴/网格）以及 UI 比例尺显示。

## 1. 运行项目

在仓库根目录执行（Windows PowerShell）：

```powershell
./gradlew :lwjgl3:run
```

## 2. 验证清单（手工）

1. 进入任意可自由缩放的视角场景。
2. 鼠标滚轮或快捷键改变缩放（zoom）。
3. 按下 **F3**：
   - 画面中出现：
     - 世界坐标轴（X=红、Y=绿、Z=蓝），基于世界原点 (0,0,0)
     - XY 平面网格线
   - 画面 UI 中出现 DebugOverlay 文本：
     - 相机中心点世界坐标（分层坐标 + km 可读格式）
     - zoom 值
     - 比例尺：`1px = N [unit]`
4. 再次按下 **F3**：上述世界渲染元素和 UI 全部消失。

## 3. 关键验收点

- 网格间距随 zoom 自适应，目标相邻网格线屏幕间距约 100px。
- 网格绘制范围自适应：覆盖可见范围并额外 1.2x 余量；缩放/移动时不出现屏幕内缺线。
- 最大放大（zoom=1.0）时比例尺显示为 `1px = 1.00 km`。

## 4. 常见问题排查

- 若 F3 无效：确认输入系统是否全局监听到 F3，并正确切换 Debug 模式。
- 若坐标轴/网格不显示：确认渲染调用发生在相机渲染链路中，并且 `ShapeRenderer`/线段批次启用。
- 若缩放时网格抖动：检查“漂亮数步长”切换条件，避免阈值过于敏感。
