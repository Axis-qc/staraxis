# ai_system 模块目录结构

> `ai_system` 是一个独立的 Python 进程，作为游戏内 AI 助手的“大脑”，通过 WebSocket 与 `webnet` 通信，并提供工具调用（Tool Call）能力喵。

---

ai_system/
|-- requirements.txt            # **依赖清单**：列出项目运行所需的 Python 第三方库喵。
|-- run_agent.bat               # **启动脚本**：快速启动 AI Agent 进程的批处理文件喵。
|-- 文件结构.md                  # 本文件：提供 ai_system 模块的逐文件枚举与职责索引喵。
|
|-- config/                     # **应用配置**喵。
|   `-- config.yaml             # **核心配置文件**：包含模型参数、API 密钥、服务端地址等喵。
|
|-- data/                       # **持久化数据**喵。
|   `-- context.json            # **上下文存储**：记录 AI 助手的对话历史或临时记忆喵。
|
|-- logs/                       # **运行日志**：存放 AI 系统的运行日志文件喵。
|
|-- runtime/                    # **运行环境**喵。
|   `-- python312/              # **便携式 Python 解释器**：确保跨机器运行的版本一致性喵。
|
|-- scripts/                    # **运维脚本**喵。
|   |-- build_vendor.ps1        # **依赖打包脚本**：将第三方库下载并整理到 vendor 目录喵。
|   `-- setup_runtime.ps1       # **环境初始化脚本**：自动下载并配置 Python 运行时喵。
|
|-- src/ai_system/              # **源代码核心目录**喵。
|   |-- main.py                 # **主程序入口**：初始化各组件并启动异步主循环喵。
|   |-- api/                    # **本地 API 服务**喵。
|   |   |-- __init__.py         # 模块初始化喵。
|   |   `-- http_server.py      # **HTTP 服务端**：提供本地管理或调试用的 API 接口喵。
|   |-- brain/                  # **认知核心**喵。
|   |   `-- openai_provider.py  # **LLM 适配器**：封装与 OpenAI/兼容接口的对话逻辑喵。
|   |-- config/                 # **配置加载器**喵。
|   |   `-- loader.py           # **YAML 加载逻辑**：解析并验证 config.yaml 的结构喵。
|   |-- protocol/               # **通信协议实现**喵。
|   |   `-- ws_client.py        # **WS 客户端**：实现与 webnet /ws/ai 的心跳、握手与消息路由喵。
|   `-- tools/                  # **工具调用（Tool Call）实现**喵。
|       |-- registry.py         # **工具注册表**：管理所有可被 AI 调用的函数元数据喵。
|       `-- snapshot_tools.py   # **快照工具集**：实现获取实体信息、星系摘要等具体工具逻辑喵。
|
`-- vendor/                     # **第三方依赖库（已省略内部细节）**：包含 aiohttp, pydantic, PyYAML, websockets 等依赖喵。
