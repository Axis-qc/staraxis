# ai_system 文件结构

本目录负责 StarAxis 游戏的外部智能体（Agent）系统接入，采用 Python 3.12 内置化分发方案喵。

## 目录树状图

```text
ai_system/
├── config/                 # 配置文件目录
│   └── config.yaml         # 核心配置文件（含 API Key、连接参数等）
├── runtime/                # [构建产物] 内置 Python 运行时
│   └── python312/          # Python 3.12 Embeddable 解释器目录
├── vendor/                 # [构建产物] 第三方依赖库（离线 site-packages）
├── src/                    # 源码根目录
│   └── ai_system/          # 核心包名
│       ├── brain/          # 智能大脑层（LLM Provider 接入）
│       ├── protocol/       # 底层通信层（WebSocket/HTTP 协议封装）
│       ├── tools/          # 工具系统层（游戏 API 封装与注册）
│       ├── config/         # 配置加载逻辑
│       └── main.py         # 智能体启动入口
├── scripts/                # 构建与维护脚本
│   ├── setup_runtime.ps1   # 下载并配置内置 Python 环境
│   └── build_vendor.ps1    # 安装依赖到 vendor 目录
├── logs/                   # [运行产物] AI 运行日志
├── requirements.txt        # 依赖声明文件
├── run_agent.bat           # 玩家一键启动脚本
└── 文件结构.md             # 本文档
```

## 目录职责说明

### config/
- **职责**：存放所有可变配置喵。
- **说明**：`config.yaml` 包含 API 地址、模型名称、API Key 以及 AI 助手的身份设定喵。

### runtime/
- **职责**：提供独立的 Python 运行环境喵。
- **说明**：通过内置 Python 3.12 确保玩家无需安装全局 Python 环境即可运行喵。

### vendor/
- **职责**：存放离线化的第三方依赖库喵。
- **说明**：包含 `websockets`、`requests`、`pydantic` 等 AI 系统运行所需的库喵。

### src/ai_system/
- **职责**：智能体核心逻辑喵。
- **brain/**：负责与大模型（如 OpenAI/Claude）通信，管理 Prompt 与上下文喵。
- **protocol/**：负责与 `webnet` 后端的 WebSocket 通信、鉴权与消息路由喵。
- **tools/**：将游戏功能（如查询星球、发送命令）封装为 AI 可调用的工具喵。

### scripts/
- **职责**：自动化构建工具喵。
- **说明**：用于下载环境和安装依赖，支持“构建期”自动化处理喵。

### run_agent.bat
- **职责**：一键启动入口喵。
- **说明**：自动设置环境变量（PYTHONPATH 等）并调用内置解释器启动智能体喵。
